Сделать правильный путь коротким

Интерактивное сравнение двух конкретных TypeScript-форм для session check, сохранения Course Page и сохранения Attempt Review. Никаких production-изменений: этот файл нужен, чтобы выбрать interface и границы enforcement.

Вопрос прототипа

Достаточен ли малый transport kernel с operation-owned decoder, чтобы соблюдение remote-data contract стало default, или декларативная таблица HTTP outcomes даёт заметно больше leverage, оправдывающее endpoint DSL?

Предварительный выбор: малый transport kernel. Пройдите сценарии ниже и проверьте, не теряем ли мы важный default.

  • Session check Сейчас Axios + feature-level mock branch; 401 уже моделируется как data.
  • Course Page save Сейчас in-process mock возвращает полный CoursePage и запускает broad invalidation.
  • Attempt Review save Сейчас in-process mock возвращает aggregate; mutation retries явно не заданы.

      Минимальный static enforcement

      Что сделать невозможным или заметным

      Без custom ESLint plugin и без попытки кодировать endpoint semantics в lint.

      Lint

      Один transport path

      Запретить axios, прямой fetch вне src/app/remote-data/http.ts и production-imports из api/mock.

      Types

      Response не пересекает feature operation

      Экспортируемая операция возвращает domain outcome или reject-ит OperationFailure. Generic в readJson безопасен только потому, что внутри всегда вызывается Valibot.

      Behavior

      Не притворяться, что lint знает контракт

      Полноту status classification, cache scope и retryability подтверждают contract scenarios. DSL/custom rule ради их статической проверки не вводится.

      Рекомендуемая форма

      Transport kernel + operation-owned decoder

      1. runHttpOperation владеет единственным вызовом Fetch и network normalization.
      2. readJson владеет unknown → Valibot → DTO и body/validation failures.
      3. Feature operation владеет status → declared outcome, DTO → domain и operation name.
      4. TanStack Query владеет signal forwarding, cache effects и явным opt-in retry.
      5. QueryClient задаёт безопасный default: automatic retries выключены и для queries, и для mutations.
      6. MSW перехватывает те же URL; никакой mock/real ветки в feature-коде нет.
      HITL check

      Принимаем эту форму, если явный status switch считается полезной локальной спецификацией операции, а не досадным boilerplate.

      Выбираем декларативные outcomes только если краткость обычных JSON endpoints важнее стоимости второго endpoint-language и его escape hatches.
