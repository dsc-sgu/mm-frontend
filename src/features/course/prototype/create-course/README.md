# Прототип создания курса

Одноразовый прототип для тикета `mm-277`: какая компоновка помогает преподавателю быстро создать курс с понятным адресом? Пять вариантов на существующей главной странице, переключаемые через `/?variant=A`, `/?variant=B`, `/?variant=C`, `/?variant=D`, `/?variant=E` и нижнюю панель.

Запуск: `bun run dev:prototype`. Прототип доступен в режиме разработки и демосборке (`PROTOTYPES_ENABLED`, `bun run build:demo`). Созданный курс регистрируется в общем мок-бэкенде в оперативной памяти и появляется в обычном списке курсов через общий запрос и существующую карточку. Запросов на создание курса к настоящему бэкенду нет. После перезагрузки данные прототипа исчезают.

## Компоновки

- **A — «Короткая форма».** Компактное окно, четыре обязательных поля и пояснение про подготовку. Минимум нового для пользователя; опора — [Bonsai](https://mobbin.com/screens/7aff0ea0-4001-4c46-ab6a-83375db02e2c).
- **B — «Сначала название».** Название получает главный визуальный акцент, ниже видны адрес и то, что появится после создания. Фиксированный префикс отделён от редактируемого адреса; опора — [Plane](https://mobbin.com/screens/8f90e5c2-c6f0-4115-9c19-0e6296bafba2).
- **C — «С предпросмотром».** Слева живая карточка курса, справа форма: вид результата помогает связать название с будущим списком. На узком экране карточка размещается сверху; опора — [Behance](https://mobbin.com/screens/a75aabb3-2166-44f7-aeca-374f2b6438b9).

- **D — «Без подсказок».** Основа A с крупным полем названия из B, без иконки. Убраны подзаголовок, пояснение адреса до проверки, подсказки внутри адреса и описания, а также сообщение о подготовке. Четыре обязательных поля и состояния проверки сохранены.

- **E — «Название — заголовок».** Основа D: название редактируется прямо в верхней части окна вместо отдельного видимого заголовка. Поле выглядит как текст, переносится на несколько строк и сохраняет доступную скрытую подпись. Остальные поля и состояния не меняются.

## Что проверять

Во всех вариантах обязательны название, короткое название, адрес и описание курса. Короткое название вводится самостоятельно и не подменяется адресом. Описание переносится в настоящий редактор страницы курса.

В нижней панели доступны успешное создание, конфликт адреса, недоступная предварительная проверка, потерянный ответ и поздний успех. Раздел «Состояние» показывает поля, режим предложения адреса и этап запроса. При неопределённом результате поля сохраняются и заморожены, повторная проверка использует ту же команду. После создания открывается существующий редактор страницы курса по адресу `/courses/$courseSlug/edit`. Он загружает созданный курс из общего мок-бэкенда; отдельного редактора или отдельной карточки для результата прототипа нет.

## Пока не подтверждено

Победитель среди компоновок не выбран. Требуется обратная связь: полезен ли предпросмотр настолько, чтобы оправдать более широкое окно? Автоматическое предложение адреса и возможность ручной правки одинаковы во всех вариантах. Цвет и типографика сохраняют нейтральный язык существующего приложения.

Это источник для обсуждения, а не готовая реализация: перенос выбранного решения в основной код требует отдельной реализации и проверки контракта с бэкендом.
