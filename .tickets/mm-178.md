# Спроектировать создание Course

## Question

Как User создаёт Course? Нужно решить:

- кто может создавать Course;
- где находится вход;
- какие поля нужны при создании, а какие настраиваются позже;
- что Course получает по умолчанию;
- нужен ли сразу следующий шаг: Student Groups, invite-ссылки, другие Teachers.

## Контекст

- Во frontend нет страницы создания Course. Dashboard показывает только «Мои курсы».
- Уже решено в [«Edit deadlines layout»](https://github.com/dsc-sgu/mm-frontend/issues/42): в каждом Course есть хотя бы одна Student Group, новый Course создаётся с одной группой по умолчанию (`CONTEXT.md`, Student Group). Управление группами и invite-ссылками — [«Управлять Student Groups курса и приглашать Students в нужную группу»](https://github.com/dsc-sgu/mm-frontend/issues/176).
- Course Access State начинается в `draft`. Students получают доступ только после открытия Course (`CONTEXT.md`).
- Карточка Course во frontend показывает полное и короткое название и цвет. Route использует изменяемый slug, а не identity Course.

## Факты backend

_Проверено на `mm-backend@ddd9849` (`main`)._

- `POST /courses` ([`internal/api.go` L107-L111](https://github.com/dsc-sgu/mm-backend/blob/ddd98496d1293a3cf9844201e70376b3364fdcc3/internal/api.go#L107-L111)) принимает `name` (обязательно) и `disciplineID` (необязательно) ([`internal/courses/repo.go` L23-L26](https://github.com/dsc-sgu/mm-backend/blob/ddd98496d1293a3cf9844201e70376b3364fdcc3/internal/courses/repo.go#L23-L26)). Глобальную роль backend не проверяет: Course создаёт любой вошедший User.
- Создатель становится `owner_id` и сразу получает Course Membership с ролью Teacher. В той же транзакции создаётся и публикуется начальный Course Snapshot ([`internal/pg/courses.go` L89-L202](https://github.com/dsc-sgu/mm-backend/blob/ddd98496d1293a3cf9844201e70376b3364fdcc3/internal/pg/courses.go#L89-L202)).
- Есть CRUD дисциплин (`/disciplines`). Название Course уникально в пределах дисциплины.
- Student Group по умолчанию при создании не появляется: `groups` и `course_users_groups` код не использует.

## Что обсудить

- Кто создаёт Course: любой User, как сейчас на backend, или только отдельная роль.
- Вход: кнопка на dashboard, отдельный маршрут, пустое состояние «Мои курсы».
- Минимальные поля: название, короткое название, цвет, slug, дисциплина. Какие из них можно оставить на потом.
- Название группы по умолчанию и можно ли переименовать её сразу.
- Одна форма или мастер с шагами (группы, invite-ссылки, Teachers).
- Создание Course копией прошлогоднего Course той же дисциплины: в этом же сценарии или отдельно.
- Новые вопросы к backend добавить в [«Реестр frontend-вопросов к backend API»](https://github.com/dsc-sgu/mm-frontend/issues/113).
