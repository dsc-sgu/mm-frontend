# Course home page layout

Верхняя часть похожа на компонент карточки курса в списке курсов на дашборде. Она содержить

- Название курса
- Описание курса
- Список преподавателей
- Иконка курса

Нижняя часть содержит какой-то произвольный контент. Контент делится на блоки:

- Параграфы
- Заголовки трёх уровней
- Цитаты
- Нумерованные списки
- Ненумерованные списки
- Спойлеры
- Блоки кода
- Картинки
- Файлы
- Задание

Текст внутри блоков может быть:

- Жирным
- Курсивным
- Ссылкой (внутри MergeMinds, а также на внешние ресурсы)

В рамках данного issue надо сделать моковый API на фронтенде.
