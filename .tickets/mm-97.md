# Исследовать React abstraction для persistent browser preferences

## Parent

mm-63 «Согласовать карту реализованной frontend-системы»

## What to build

Исследовать поддерживаемые способы работы с persistent browser preferences в текущем React-стеке и закрепить выводы отдельным research-коммитом. Production behavior не меняется.

## Acceptance criteria

- [ ] Сравнены maintained libraries, небольшой project-level adapter и feature-local hooks.
- [ ] Проверены same-tab и cross-tab synchronization semantics.
- [ ] Рассмотрены validation, versioning/migrations, serialization и удаление устаревших данных.
- [ ] Рассмотрены unavailable storage, quota/security errors и restricted contexts.
- [ ] Отдельно исследованы pre-React initialization и предотвращение theme flash.
- [ ] Зафиксировано, почему root HTML class остаётся runtime source of truth темы.
- [ ] Рекомендации опубликованы в отдельной research-ветке с commit permalink.
- [ ] Перечислены решения владельца проекта до implementation tickets.
