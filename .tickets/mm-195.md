# Показывать файл целиком в diff Attempt review

## Source

- Страница AnyType «Разбор состояния фронтенда MergeMinds на 6.06.2026», №4: переключатель на полный файл нужен, в GitLab без него неудобно.

## Проблема

Diff в Attempt review показывает только изменённые фрагменты с небольшим контекстом. Чтобы увидеть код вокруг изменения целиком, Teacher'у приходится открывать файл где-то ещё.

## Что известно

- `@pierre/diffs` умеет раскрывать неизменённые строки (`expandUnchanged`, раскрытие между hunks), только если diff построен из полного содержимого файлов, а не из patch.
- Mock строит diff из полного старого и нового текста (`parseDiffFromFile` в `src/features/course/features/attempt-review/api/mock.ts`).
- По решению mm-116 «Спроектировать Review → Grade → Student result vertical» frontend получает полное старое и новое содержимое каждой записи changed-files manifest. В [«Ezhkin-Kot/fixes»](https://github.com/dsc-sgu/mm-backend/pull/172) `oldText`/`newText` содержат только удалённые и добавленные строки. Вопрос уже есть в mm-113 «Реестр frontend-вопросов к backend API», раздел про выдачу изменений Attempt.

## Что делает

- В заголовке файла есть переключатель «Показать файл целиком». Включённый, он показывает весь файл с подсветкой изменений.
- Line Comment Threads остаются на своих строках в обоих режимах.
- Для записей `binary` и `too-large` переключателя нет.

## Что решить

- Только для отдельного файла или ещё общий переключатель на всю Attempt.
- Запоминать ли выбор между файлами и Attempts.

## Зависит от

Полного содержимого файлов от backend: см. mm-113.
