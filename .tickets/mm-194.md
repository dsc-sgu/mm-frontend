# Подписать кнопки unified/split в Attempt review

## Source

- Страница AnyType «Разбор состояния фронтенда MergeMinds на 6.06.2026», №3: начинающий пользователь не поймёт, что это за кнопки; нужно помогать текстом при наведении.

## Проблема

Переключатель режима diff (`src/features/course/features/attempt-review/ui/diff-view-toggle.tsx`) состоит из двух кнопок с одними иконками `SquareSplitVertical` и `SquareSplitHorizontal`. У кнопок нет ни текста, ни подсказки, ни `aria-label`: подпись «Режим отображения diff» есть только у группы. Screen reader объявляет кнопку как «нажата» или «не нажата», без названия режима.

## Что делает

- У каждой кнопки подсказка при наведении и при фокусе с клавиатуры, например «В одну колонку» и «В две колонки». Подсказка — shadcn `tooltip` из `src/shadcn/components/ui/tooltip.tsx`.
- Тот же текст становится доступным именем кнопки.
- Состояние `aria-pressed` остаётся как есть.
