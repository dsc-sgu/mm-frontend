# Журнал студента: свои оценки по всем заданиям курса

## Проблема

Ссылка «Журнал» видна студенту, но ведёт на английскую заглушку «Journal page» (`src/routes/_authenticated/courses/$courseSlug/journal.tsx`). В закрытом mm-99 решено, что студент видит в журнале только свои опубликованные оценки по всем заданиям и простую сумму. Тикета на реализацию нет. mm-26 описывает только общую таблицу преподавателя.

## Что делает

Вертикаль: экран, операция чтения на Fetch, MSW-handler, тесты доступа.

- Студент на `/courses/$courseSlug/journal` видит задания курса в порядке страницы курса. По каждому заданию — последняя опубликованная оценка из максимальной, статус («не сдано», «на проверке», «проверено»), ссылка на попытку.
- Внизу — сумма полученных оценок и сумма максимальных.
- Студент никогда не видит оценки других студентов (решение mm-99). Проверяется тестом доступа.
- Оценка совпадает с той, что на странице попытки и в истории попыток: одна оценка на всех экранах (эпик mm-218).

## Что решить

- Порядок с mm-26: один маршрут с двумя представлениями, по роли.
- Какая оценка идёт в журнал, если попыток несколько: последней проверенной попытки или лучшая.
- Бэкенда оценок пока нет (mm-113, «Модель проверки и точность оценки»); экран строится на мок-бэкенде по рабочему контракту.
