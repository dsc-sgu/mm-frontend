# Добавить rendered-режим для Markdown-диффов

## What to build

При просмотре изменений попытки пользователь должен иметь возможность переключить Markdown-файл из обычного исходного диффа в отрендерованное представление изменений, аналогично режиму Rich diff в GitHub. Отрендерованный режим должен показывать форматирование Markdown и при этом сохранять понятное различие между добавленным и удалённым содержимым. Пользователь в любой момент может вернуться к исходному диффу.

## Acceptance criteria

- [ ] Для изменённых Markdown-файлов в заголовке файла доступно понятное переключение между исходным и отрендерованным представлением; для остальных типов файлов интерфейс не меняется.
- [ ] Исходный режим продолжает показывать текущий построчный дифф без регрессий, включая работу существующих комментариев.
- [ ] Отрендерованный режим отображает Markdown-форматирование и визуально различает добавленное и удалённое содержимое для изменённых, добавленных и удалённых файлов.
- [ ] Переключение режима не теряет черновики комментариев и другое состояние текущего ревью.
- [ ] Потенциально небезопасный HTML и ссылки из Markdown не могут выполнить произвольный код или внедрить небезопасную разметку.
- [ ] Некорректный или неподдерживаемый Markdown не ломает страницу: пользователь видит доступное представление и может вернуться к исходному диффу.
- [ ] Поведение определения Markdown-файлов, переключения режимов и отображения основных видов изменений покрыто автоматическими тестами.
