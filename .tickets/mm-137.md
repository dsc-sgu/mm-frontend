# Обновить React, Tailwind, React Virtual и Pierre Trees

## Источники

- mm-71 (аудит зависимостей и конкурирующих библиотек), дополнение «Ревизия доступных версий»: когорта 8 (cohort 8), React Virtual и Pierre Trees.
- mm-69 (последовательность подготовки и выполнения рефакторинга): эти обновления не попали ни в один этап последовательности.

## Что сделать

Каждый пункт — свой PR с проверкой: `bun run lint`, `bun run build` и все наборы тестов, которые к тому моменту есть в CI, проходят.

- [ ] React и React DOM 19.2 → 19.3 вместе с `@types/react` и `@types/react-dom`.
- [ ] Tailwind CSS и `@tailwindcss/vite` 4.1 → 4.3 вместе, затем `prettier-plugin-tailwindcss` 0.8.0 → 0.8.1.
- [ ] `@tanstack/react-virtual` 3.13 → 3.14. Используется в списке попыток курса (`attempts/ui/virtualized-list.tsx`) и календаре дедлайнов (`deadlines-calendar/calendar.tsx`).
- [ ] `@pierre/trees` beta.4 → beta.6. Используется в дереве файлов на странице попытки (`attempt-review/ui/file-tree.tsx`). Это бета-версия: нужно вручную бегло проверить дерево файлов (smoke-проверка).

Версии указаны на момент аудита; перед началом проверить актуальные через `bun outdated`.

## Когда брать

Действует правило зон из mm-69. React Virtual и Pierre Trees задевают зоны «Список попыток курса» (Course Attempts) и «Проверка» (Review), поэтому их берут прямо перед этапом своей зоны или после её этапов. Подходящие этапы: ATT4 (раскладки строки) или DEADLINES для React Virtual, REV3 (материал попытки) для Pierre Trees.

React и Tailwind задевают всё приложение. Их лучше ставить после CH, когда Playwright в трёх движках уже работает в CI, и не параллельно с этапами редактора страницы курса.
