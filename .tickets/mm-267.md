# Тесты доступа: константа идентификатора курса без суффикса _ID в participant-resources.test.ts

В `src/features/course/features/access/api/participant-resources.test.ts:29` идентификатор курса лежит в константе без суффикса:

```ts
const COURSE = accessWorld.courses.algorithms.id;
```

В тестах проверки (`review/api/load-review.test.ts`) и проверки попытки (`attempt-review/api/read-operations.test.ts`, `attempt-review/page.test.tsx`) такая константа уже называется `COURSE_ID`. По имени `COURSE` легко решить, что это сам курс, а не его идентификатор.

## Что сделать

- Переименовать `COURSE` в `COURSE_ID` во всём файле (сейчас 32 вхождения).
- Прогнать Prettier: некоторые строки после переименования могут стать длиннее лимита.

## Критерии приёмки

- [ ] В `participant-resources.test.ts` нет константы `COURSE`, идентификатор курса хранится в `COURSE_ID`.
- [ ] Тесты файла проходят, `bun run lint` чистый.
