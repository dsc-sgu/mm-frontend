# Показывать ровно один файл в блоке страницы курса

## Решение

На один блок страницы курса должен приходиться ровно один файл. Пользователь подтвердил изменение интерфейса и попросил выполнить его отдельным тикетом с приоритетом P0.

## Проблема

Сейчас блок `files` содержит `data.fileIds: string[]` и отображает несколько файлов. Документ, редактор и интерфейс вставки поддерживают групповой блок вместо отдельного блока на каждый файл.

## Ожидаемое поведение

Каждый файл на странице курса представлен самостоятельным блоком. Преподаватель вставляет, перемещает и удаляет каждый такой блок отдельно.

## Критерии приёмки

- В модели документа блок файла содержит один `fileId`, а не массив `fileIds`. Название типа и команды соответствуют одному файлу.
- При выборе нескольких файлов создаётся отдельный блок для каждого выбранного файла; их порядок соответствует порядку выбора. Объединять несколько файлов в один блок нельзя.
- Интерфейс вставки, команды редактора, адаптер Plate и режим чтения используют один контракт. Перемещение, дублирование и удаление действуют на один блок файла.
- Метаданные файла остаются в ресурсах и находятся по `fileId`. Если ресурс отсутствует, на месте блока показывается «Файл курса недоступен».
- Фикстуры, моки и тесты переведены на новый формат. Прежний групповой путь удалён. Если к моменту реализации существуют сохранённые документы прежнего формата, предусмотрено явное преобразование каждого группового блока в последовательность отдельных блоков с сохранением порядка и без потери ссылок; без молчаливого принятия несовместимых данных под прежней версией формата.
- Сохранение и повторное открытие сохраняют порядок и ссылки на файлы. Применимые контракты доступности сохранены; проходят линтер, сборка и проверки владельца контракта, браузерные сценарии в Chromium, Firefox и WebKit.

## Места в коде

- `src/features/course/features/page-document/model/document.ts`: схема блока файлов.
- `src/features/course/features/page-document/ui/blocks.tsx`: режим чтения.
- `src/features/course/features/page-edit/model/plate-content.ts`: адаптер Plate.
- `src/features/course/features/page-edit/model/block-operations.ts`: команды вставки и изменения блоков.
- `src/features/course/features/page-edit/ui/plate/nodes.tsx`: отображение блока в редакторе.
- Интерфейс выбора и вставки файлов, ресурсы и фикстуры страницы курса.

Если пути переименованы, использовать актуальные модули с теми же владельцами поведения.
