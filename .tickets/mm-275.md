# Реакция оболочки курса на отказ: стоимость события кэша не зависит от размера кэша

Часть эпика mm-218, волна 3. После mm-243 оболочка курса замечает отказ в чтении страницы через `useResourceDenial` (`access/hooks/use-resource-denial.ts`). Перед началом прочитать [`docs/agents/remote-data.md`](https://github.com/dsc-sgu/mm-frontend/blob/main/docs/agents/remote-data.md) (обязательно по `AGENTS.md`).

## Проблема

На каждое событие `QueryCache` хук вызывает `hasObservedResourceDenial`, а та обходит **весь** кэш через `findAll`. Индекса по префиксу у `QueryCache` нет, поэтому префикс `courseKeys.byId(courseId)` от обхода не спасает. Стоимость одного события — O(размер кэша), включая запросы, не относящиеся к курсу: листание календаря дедлайнов делает дороже каждое событие на странице курса. С содержимым по записям манифеста (mm-224) одна страница попытки сама создаёт сотни запросов и сотни событий, и затраты растут квадратично.

## Делает

Инкрементальный подсчёт наблюдаемых отказов: на событие обновляется ответ только для `event.query`.

- **Предикат для одного запроса** — `isObservedResourceDenial(query, courseId)` в `access/api/resource-denial.ts`: запрос под префиксом курса (`matchQuery`), у него есть наблюдатель, данные — `ResourceDenial`. `hasObservedResourceDenial` удаляется.
- **Чистый переход** — `syncDenial(denied, queryHash, isObservedDenial)` в `access/model/resource-denial.ts`, рядом с `nextDeniedLocation`: `isObservedDenial ? denied.add(queryHash) : denied.delete(queryHash)` над `Set` из `immutable` (уже в зависимостях, импорт `Set as ImmutableSet`, как в `attempts/hooks/use-selection.ts`). `Immutable.Set` возвращает тот же экземпляр, если членство не изменилось, поэтому Zustand не уведомляет подписчиков.
- **Vanilla-стор Zustand** — `createResourceDenialStore` в `access/model/`, по образцу `createDiffReadinessStore`:
  - в состоянии `denied: ImmutableSet<string>` — хеши наблюдаемых отказов, плюс действия `start` и `stop`;
  - предикат запроса передаётся параметром (`isObservedDenial: (query) => boolean`), а не импортируется из `api/`: модель не зависит от ключей кэша, юнит-тесты стора обходятся без них;
  - подписка на `QueryCache` — в замыкании, это ресурс, а не отображаемое состояние;
  - `start()` один раз заполняет множество обходом кэша (события между рендером и эффектом не теряются), затем подписывается; событие `removed` удаляет запрос из множества; повторный `start()` ничего не делает;
  - создание стора чистое: без подписки, её делает только `start()`.
- **Хук** — `useResourceDenial`:
  - стор создаётся в `useState` и пересоздаётся при смене `courseId` подстройкой состояния при рендере (оболочка курса не обязательно размонтируется при переходе в другой курс; `useMemo` не годится — это подсказка для оптимизации, а не гарантия):
    ```ts
    const [tracked, setTracked] = useState(() => ({ courseId, store: create(courseId) }));
    if (tracked.courseId !== courseId) {
      setTracked({ courseId, store: create(courseId) });
    }
    ```
  - `useEffect` вызывает `start` и возвращает `stop`, зависимость — стор;
  - читает `useStore(store, (state) => state.denied.size > 0)`; защёлка `nextDeniedLocation`, удаление ненаблюдаемых отказов и перепроверка курса — без изменений.

## Удаляет

- `hasObservedResourceDenial` и обход кэша на каждое событие.
- Прямой импорт `useSyncExternalStore` в `use-resource-denial.ts`, его исключение в `eslint.config.js` (`EXTERNAL_SOURCE_ADAPTERS`) и абзац об исключении в `AGENTS.md` («Where state lives»).

## Не входит

- Поведение оболочки при отказе: защёлка по адресу, удаление отказов, перепроверка курса.

## Контракты

| Слой | Сценарий | Ожидание |
|---|---|---|
| Unit | `syncDenial`: добавление, удаление, повтор того же события | повтор возвращает тот же экземпляр множества |
| Unit | стор: событие запроса вне курса | `denied` не меняется, подписчики не уведомлены |
| Unit | стор: у отказа ушёл последний наблюдатель / запрос удалён из кэша | хеш уходит из `denied` |
| Unit | стор: отказ появился до `start()` | `start()` находит его обходом |
| Unit | стор: `start` → `stop` → `start` (`StrictMode`) | одна живая подписка, множество актуально |
| Component | смена курса без размонтирования оболочки | отказ прежнего курса не закрывает новый |
| Component | контракты `access/resource-denial-routes.test.tsx` | без изменений, зелёные |

## Готово, когда

- Стоимость события кэша не зависит от числа запросов вне курса.
- Замер на стресс-попытке (160 файлов) после mm-224 показывает, что обработка событий не растёт с размером кэша.
- `useSyncExternalStore` снова разрешён только адаптерам к API браузера; исключение убрано из `eslint.config.js` и `AGENTS.md`.
- `bun run lint`, `bun run build`, `bun run test` и тесты Playwright проходят.
