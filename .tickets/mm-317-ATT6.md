# ATT6: Публиковать первые проверки в режиме быстрого оценивания

## Цель

Сессия по mm-114: только первые проверки, фиксированные применённые фильтры, отдельные исходы каждой попытки и отклонённые оценки. Общий отзыв — поле в строке. Mod+S сохраняет и фокусирует первую ошибку; Alt+G входит только без неприменённых фильтров. Esc при неопубликованных значениях открывает диалог с фокусом на «Остаться»; закрытие popover не выходит из режима.

## Удаляет или заменяет

Массовую максимальную оценку и старый путь быстрого оценивания через RAM-моки; второй владелец публикации не появляется.

## Принятое решение и границы

Владелец подтвердил frontend-first подход: существующий API-слой бэкенда заменяется контрактами, определёнными потребностями фронтенда. Модель черновиков блоков, публикации со слиянием и чекпоинтов согласована. Ожидание старого API не блокирует этап. HTTP-формы и исходы операции закрепляются в схемах, MSW и тестах; вопросы о реализации и оставшиеся ограничения фиксируются в mm-113.

Перед реализацией прочитать `docs/agents/remote-data.md`, актуальный `CONTEXT.md` и связанные ADR. Устаревшие положения ADR 0002 и ADR 0004 о брони редактирования курса заменяются решением mm-286; бронь проверки сохраняется. Изменения доменной документации учитывает mm-286.

Новая архитектура не требует переименования каталогов из mm-292 заранее: использовать текущие пути с теми же владельцами поведения. Не выделять отдельное «чистое ядро». Этап выполняется заменой за один шаг без второго временного пути данных.

## Проверяемое поведение

- `QG-01`: Режим: поле есть только у непроверенных попыток; повторное «Сохранить» шлёт только изменённые; успешные строки становятся сохранёнными; режим остаётся открытым.
- `QG-02`: Свёртка исходов по каждой попытке: сохранено / конфликт брони / проверка уже есть / иной отказ → состояние строки и записи восстановления; успешные не откатываются.
- `QG-03`: Неизвестный исход пакета → записи ждут исхода → пакет повторяется с теми же ключами идемпотентности для каждой попытки → сохранено / конфликт / не проверено; это не объявляется провалом и не публикует вторую проверку; авторитетные проверки перечитываются только для проекций.
- `QG-04`: Смешанный пакет: сохранённая оценка есть в MSW, конфликт → запись восстановления. Состояние быстрого оценивания (изменённые, ждущие исхода, восстановление) хранится отдельно от кэша Query, по `AttemptId`; инвалидация списка попыток курса его не меняет и до выхода из режима не перезапрашивает список.
- `QG-05`: Фильтры заблокированы во время быстрого оценивания; однострочный общий отзыв сохраняется как `ReviewTextDocument` из одного абзаца.
- `QG-06`: Конфликт → итоговое окно; панель восстановления доступна и после его закрытия; запись: ФИО, задание, номер попытки, оценка/maxGrade, ссылка, причина, держатель брони или автор и оценка опубликованной проверки; скопировать одну или все, TXT, удалить.
- `QG-07`: Выход, смена маршрута или перезагрузка, когда есть изменённые записи или оставшиеся записи восстановления, → подтверждение с предложением скопировать или скачать.
- `QG-09`: Обновление строки во время режима (событие брони, перечитывание проверок, явное обновление): изменённая запись у попытки, которая стала проверенной, → запись восстановления «Проверка уже появилась» с автором и оценкой; записи, ждущие исхода, не трогаются до исхода повтора пакета; записи, введённые, пока пакет в полёте, остаются изменёнными.
- `QG-10`: Во время быстрого оценивания возврат фокуса, восстановление сети и инвалидация после пакета дают 0 запросов списка попыток курса; выход из режима — ровно один повторный запрос.
- `QG-11`: Набор строк зафиксирован до выхода из режима: сохранённые и конфликтные строки остаются видимыми со своим состоянием даже при фильтре `submitted`; введённые значения переживают размонтирование строк виртуализацией.
- `QG-08`: Высота строки не меняется, когда открывается поле общего отзыва или появляется восстановление.
- `QG-12`: `Esc` при несохранённых или неопубликованных значениях → диалог с фокусом на «Остаться»; `Enter` в нём не выходит из режима; если открыт popover или диалог, `Esc` сначала закрывает его.
- `QG-13`: `Mod+S` сохраняет и не открывает браузерное «Сохранить страницу»; при ошибке фокус переходит на первую ошибку.
- `QG-14`: `⌥G` / `Alt+G` по физической клавише, в том числе на русской раскладке, включает быстрое оценивание, только если нет неприменённых изменений фильтров.
- `QG-E1`: Анна оценивает три попытки, одну из них параллельно оценил Борис → частичный исход виден явно; две проверки видны студентам; третья — в восстановлении.

Публикация и бронь используют операции владельца review. Операции быстро оценивания определяют удобный фронтенду API; перед реализацией сверить исходы mm-114 целиком.

## Готово, когда

- [ ] Реализовано описанное поведение и удалён прежний путь в затронутой зоне.
- [ ] Схемы, моки и тесты используют один контракт; отказ, отмена и неизвестный исход не изображаются успехом.
- [ ] Проходят `bun run lint`, `bun run build` и проверки уровня владельца контракта; браузерные сценарии — в Chromium, Firefox и WebKit.
- [ ] Сохранены применимые общие контракты доступности `A11Y-01` и `A11Y-02`.
