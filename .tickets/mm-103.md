# Возвращать преподавателя в рабочую очередь после проверки

## Делает

Делает путь «рабочая очередь → проверка попытки → рабочая очередь» непрерывным. Преподаватель, открывший проверку из применённой выборки, возвращается к тем же фильтрам и подходящей позиции списка и не собирает рабочий контекст заново. Обычный переход в раздел «Попытки» остаётся предсказуемым и не зависит от случайно сохранённой старой позиции.

## Готово, когда

- [ ] Применённые фильтры очереди по-прежнему записаны в URL и восстанавливаются после перезагрузки.
- [ ] Попытка, открытая из отфильтрованной очереди, получает достаточно контекста, чтобы продолжить этот сценарий.
- [ ] Возврат из проверки по пути продолжения работы открывает ту же применённую выборку.
- [ ] После возврата преподаватель видит исходную попытку или ближайшую устойчивую позицию, даже если список виртуализирован.
- [ ] Если состав списка изменился и исходной попытки больше нет, срабатывает понятный безопасный запасной вариант, а не ошибочная прокрутка к абсолютной позиции.
- [ ] Обычный переход во вкладку «Попытки» не обязан восстанавливать старую рабочую позицию и отличим от продолжения очереди.
- [ ] Прямое открытие проверки без контекста очереди продолжает работать.
- [ ] Поведение проверено в настоящем приложении с маршрутизацией на мок-сценарии преподавателя.
- [ ] Нетривиальная сериализация или восстановление контекста покрыты отдельным модельным тестом, только если для них появился чистый интерфейс.
