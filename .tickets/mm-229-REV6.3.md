# REV6.3: Предупреждать об уходе с несохранённой рабочей копией проверки

Часть эпика mm-218.

Преподаватель не теряет неопубликованную рабочую копию проверки случайно: уход, переключение попытки, перезагрузка и закрытие вкладки требуют подтверждения. Просмотр без изменений уход не блокирует.

### Делает

- **Что считается несохранённым.** Рабочая копия, отличная от последней версии проверки: оценка, общий отзыв и собственные комментарии преподавателя. Ответы публикуются сразу и не учитываются.
- **Когда нужно подтверждение:**
  - навигация по приложению;
  - переключение попытки через селектор попыток;
  - перезагрузка и закрытие вкладки через `beforeunload`.
- **`publication-unconfirmed`:** уход предупреждает «Публикация не подтверждена».
- **Без блокировки:** страница попытки и редактор проверки без изменений.
- **Точка для брони.** Действия, которые должны выполниться только после подтверждённого ухода, получают единую точку. Снятие брони подключит REV7.1.

### Не входит

- Снятие брони проверки — REV7.1.
- Правило «предупреждать, только если нет совместимой лайв-копии» — REV7.3.

### Уточнения

mm-87 (предупреждение об уходе с несохранённой проверки попытки) и его комментарий о связи с вертикалью проверки: после явного сброса изменений или успешной публикации предупреждение исчезает; просмотр только для чтения и проверка без локальных изменений уход не блокируют; новые свои комментарии учитываются как несохранённая работа.
