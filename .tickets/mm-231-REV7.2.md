# REV7.2: Делить редактор проверки между вкладками — живая копия и «Продолжить здесь»

Часть эпика mm-218.

Вкладки одного браузера делят редактор проверки. Пишет одна, остальные показывают живую копию рабочей копии проверки. «Продолжить здесь» переносит работу без сервера и без потерь. Закрытая пишущая вкладка передаёт работу следующей.

### Делает

Протокол из mm-132 в общем модуле `lease`. Ресурс — `mm:editor:{UserId}:review:{AttemptId}`.

**Кто пишет.**
- Запись `{epoch, writer}` в localStorage. Каждая смена увеличивает `epoch`.
- Перед каждой записью на сервер, включая heartbeat и публикацию, вкладка синхронно сверяет свой `epoch` и `UserId` сессии (`writeGuard`).
- Web Lock выбирает следующую пишущую вкладку. Копии стоят в очереди за ним.

**Живая копия.**
- BroadcastChannel доставляет полную рабочую копию после каждого изменения, в той же задаче, вместе со статусами публикации и держателем брони.
- Новая копия заменяет старую по `(epoch, seq)`. Открывшаяся вкладка спрашивает состояние сообщением `hello`.
- Копия не отправляет записей на сервер.
- Копия показывает «Редактирование идёт во вкладке N этого браузера · Продолжить здесь».

**Добровольная смена.**
- Пишущая вкладка отвечает сразу, перестаёт принимать правки и дожидается публикации в полёте.
- `publication-unconfirmed` передаётся вместе с `idempotencyKey` и замороженной рабочей копией, повторы продолжает новая вкладка.
- Переходят рабочая копия и черновики полей ввода: комментарий преподавателя, ещё не добавленный в рабочую копию, и ответ. История отмены, выделение, курсор и прокрутка теряются.
- Обращений к брони на сервере нет.

**Закрытие пишущей вкладки.**
- Web Lock переходит к первой копии в очереди. Она продолжает сама и показывает «Вкладка N закрыта — редактирование продолжено здесь».
- Бронь снимается, когда уходит последняя вкладка редактора проверки этой попытки.

**Версии.** Одно `TAB_PROTOCOL_VERSION` покрывает сообщения и рабочую копию; конверт `{kind, from, version, epoch}` не меняется. При несовпадении нет ни живой копии, ни смены: «Редактор открыт во вкладке с другой версией MergeMinds — закончите работу там и закройте её».

**Пользователь.** Канал и Web Lock привязаны к `UserId`. Вкладка другого пользователя не получает живую копию. Выход из аккаунта останавливает запись в пишущей вкладке.

**`interrupted`** видят все вкладки браузера, действовать можно из любой.

**Швы:**
- Чистые переходы (`writeGuard`, `isNewerState` и др.) — слой Model.
- Модуль получает localStorage, BroadcastChannel и Web Locks через интерфейс. В Vitest — пара фейковых вкладок с общими примитивами, заморозкой и задержанным запросом к серверу (фикстура `tabs`).
- Playwright — две страницы одного BrowserContext на общем состоянии мок-бэкенда из REV6.2.

### Не входит

- Силовая смена, вкладка без живой копии, полное поведение выхода и повторного входа, bfcache — REV7.3.
- Адаптер черновика курса — DRF4.

### Контракты

| id | Слой | Риск | Фикстуры | Контракт |
|---|---|---|---|---|
| TAB-01 | Stateful | Сохранность данных | `tabs` | Вторая вкладка того же ресурса открывается живой копией только для чтения; правки пишущей вкладки появляются в копии; копия не отправляет записей. (I5, I6) |
| TAB-02 | Stateful | Сохранность данных | `tabs` | Добровольная смена: «Продолжить здесь» → пишущая вкладка дожидается пакета синхронизации в полёте и отдаёт рабочую копию; новая продолжает с теми же правками; обращений к брони нет; счётчик смен +1. (I5, I6) |
| TAB-04 | Stateful | Целостность | `tabs` | Смена не разрывает публикацию проверки: пока исход неизвестен (в полёте или `publication-unconfirmed`), рабочая копия и `idempotencyKey` остаются у одной вкладки. (I4) |
| TAB-05 | Stateful | Целостность | `tabs` | Вкладки с разной версией протокола: рабочая копия другой версии не принимается, смены нет. |
| TAB-06 | Stateful | Доступ | `tabs` | Канал и Web Lock привязаны к `UserId` и ресурсу: вкладка другого пользователя того же браузера не получает живую копию; выход из аккаунта останавливает пишущую вкладку. |
| TAB-08 | Real browser | Сохранность данных | `tabs` | Две страницы одного контекста в трёх движках: BroadcastChannel доставляет живую копию, Web Lock держит одна вкладка, закрытие пишущей освобождает право писать. (I5, I6) |
| REV-E5 | E2E | Сохранность данных | `world:review`, `tabs` | Анна открывает ту же попытку во второй вкладке → живая копия только для чтения; оценка и комментарий из первой видны в копии; «Продолжить здесь» → рабочая копия со всеми правками редактируется во второй, первая стала копией; публикация из второй → Саша видит всё. (I5) |

TAB-02 в этом тикете проверяется с публикацией проверки в полёте вместо пакета синхронизации страницы курса. REV-32 дополняется: бронь одна на браузер для всех вкладок.

Фикстуры описаны во вкладке «Fixtures» [матрицы](https://github.com/dsc-sgu/mm-frontend/blob/ddda126c5e73ec787362805c286ee081ee26244d/docs/prototypes/test-contract-matrix.html).
