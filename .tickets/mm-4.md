# Edit profile page layout

Нужно реализовать страницу редактирования профиля. Нужно иметь возможность редактировать

- Фамилию
- Имя
- Отчество (опционально)
- Имя пользователя
- Электронную почту
- Аватарку (опционально)
- Контакты для связи (каждый из контактов опционален)
   - Почта
   - Телефон
   - Имя пользователя в Telegram
   - Адрес на сайт
- Краткая информация о себе (опционально)
- Пароль

Необходимо реализовать валидацию при помощи react-hook-form и valibot (они уже стоят в проекте). Под фамилию, имя и отчество должны быть отдельные поля. Имя пользователя и электронная почта могут быть заняты, это необходимо проверять.

Аватарку нужно иметь возможность поставить, переставить и снести. При установке и перестановке аватарки было бы здорово иметь возможность аватарку обрезать (как это делается в большом количестве соц. сетей). Ну и плюс, если загружаемая картинка не квадратная, это было бы удобно, поскольку пользователь сразу будет понимать, как аватарка обрежется под квадрат. Ну и классно было бы сделать drag-and-drop для авартка аватарки.

Для каждого текстового поля нужно установить минимальное и максимальное количество символов. Электронную почту и номер телефона надо валидировать на то, что это реально почта и телефон. Аналогично с именем пользователя в telegram и адресом на сайт.

В качестве отдельной возможности надо сделать возможность смены пароля. Пользователь должен указать текущий пароль, новый пароль и повторно новый пароль для подтверждения.

На данный момент ни на backend'е, ни на frontend'е не реализовано подтверждение почты. Но для проды это обязательно. Нужно сделать отдельный issue на реализацию подтверждение почты.

В рамках данного issue не нужно делать привязку к настоящему backend'у, нужно реализовать mock API на стороне фронтенда.
