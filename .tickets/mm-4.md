# Страница редактирования профиля

Нужно реализовать страницу редактирования профиля. Нужно иметь возможность редактировать:

- Фамилию
- Имя
- Отчество (опционально)
- Имя пользователя
- Электронную почту
- Аватарку (опционально)
- Контакты для связи (каждый из контактов опционален)
   - Почта
   - Телефон
   - Имя пользователя в Telegram
   - Адрес сайта
- Краткая информация о себе (опционально)
- Пароль

Валидацию нужно сделать на React Hook Form и Valibot (они уже стоят в проекте). Под фамилию, имя и отчество должны быть отдельные поля. Имя пользователя и электронная почта могут быть заняты, это необходимо проверять.

Аватарку нужно иметь возможность поставить, заменить и удалить. При установке и замене аватарки было бы здорово иметь возможность её обрезать (как это делается во многих соцсетях). Это особенно удобно, если загружаемая картинка не квадратная: пользователь сразу понимает, как аватарка обрежется под квадрат. И классно было бы сделать перетаскивание (drag-and-drop) для аватарки.

Для каждого текстового поля нужно установить минимальное и максимальное число символов. Электронную почту и номер телефона надо валидировать на то, что это действительно почта и телефон. Аналогично с именем пользователя в Telegram и адресом сайта.

Отдельной возможностью надо сделать смену пароля. Пользователь должен указать текущий пароль, новый пароль и ещё раз новый пароль для подтверждения.

Сейчас ни на бэкенде, ни на фронтенде нет подтверждения почты. Но для продакшена оно обязательно. Нужно завести отдельный тикет на подтверждение почты.

В рамках этого тикета не нужно подключать настоящий бэкенд: API нужно реализовать моком на MSW.
