# Перевести attempt review и обсуждение на общий mock backend

## Parent

mm-73 «Перевести frontend с RAM-моков на fetch и MSW»

## What to build

Перевести readonly diff и editable attempt review на общий mock backend. Grade, overall feedback, line comments, replies, история попыток и changed files должны обслуживаться через HTTP и строиться из одного канонического attempt/review state, сохраняя корректные course-scoped permissions и identity авторов.

## Acceptance criteria

- [ ] Attempt review и readonly diff загружаются через fetch/MSW.
- [ ] Сохранение grade, overall feedback и line comments выполняется через HTTP mutation.
- [ ] Создание, изменение и удаление replies выполняется через HTTP mutations.
- [ ] Teacher attempts list, student task history и attempt review читают одну каноническую grade.
- [ ] Преподаватель текущего курса может редактировать review и отвечать на комментарии.
- [ ] Студент-владелец попытки может отвечать на сохранённые комментарии, но не редактировать review.
- [ ] Сохранённый reply получает identity фактического текущего пользователя.
- [ ] Attempt-review feature больше не импортирует собственный stateful RAM-мок.
- [ ] Lint и build проходят.
