# Добавить воспроизводимые mock-сценарии и transport profiles

## Parent

[Перевести frontend с RAM-моков на fetch и MSW](https://github.com/dsc-sgu/mm-frontend/issues/73)

## What to build

Сделать mock backend воспроизводимым для разработки и будущих тестов: предоставить выбираемые детерминированные seed-сценарии для ключевых состояний продукта, reset между проверками и независимые transport profiles для latency и HTTP failures. Сценарий задаёт начальное состояние мира, а не набор готовых endpoint responses.

## Acceptance criteria

- [ ] Mock backend поддерживает именованные сценарии: default, student attempt history, teacher grading, review discussion, empty course, large diff и role-varies-by-course.
- [ ] Сценарий можно выбрать конфигурацией без изменения feature-кода.
- [ ] Каждый сценарий создаёт согласованный backend state из canonical entities, а не дублированных response payloads.
- [ ] Один пользователь может быть преподавателем в одном курсе и студентом в другом.
- [ ] Mock backend можно сбросить к исходному seed между ручными или автоматизированными проверками.
- [ ] Latency и error responses конфигурируются отдельно от seed-данных.
- [ ] Повторный запуск одного сценария воспроизводит те же identities и исходные данные.
- [ ] Lint и build проходят.
