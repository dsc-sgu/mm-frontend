# Создавать следующее задание через «Создать ещё»

## Parent

#100

## What to build

Позволить преподавателю после создания задания сразу начать следующее через действие «Создать ещё», не закрывая рабочий контекст курса. Новое задание создаётся рядом с предыдущим, а повторяемые настройки остаются видимыми и редактируемыми, чтобы ускорение не скрывало ошибочно скопированный дедлайн или балл.

## Acceptance criteria

- [ ] При добавлении нового блока задания открывается тот же боковой редактор, что реализован в #41.
- [ ] После успешного создания доступно явное действие «Создать ещё».
- [ ] «Создать ещё» создаёт следующий блок задания непосредственно после только что созданного блока и сохраняет контекст этого места курса.
- [ ] Название и условие следующего задания очищаются.
- [ ] Дедлайн и максимальный балл переносятся как видимые редактируемые значения; пользователь может изменить их до применения.
- [ ] Ни одно перенесённое значение не скрыто за свёрнутой секцией или неявным preset.
- [ ] Отмена второго задания не удаляет и не откатывает уже созданное первое.
- [ ] Успешное создание обновляет документ курса и доступность отдельной страницы нового задания через согласованный mock/query interface.
- [ ] Серия из нескольких заданий сохраняет правильный порядок блоков и уникальную идентичность каждого задания.
- [ ] Сценарий не добавляет изменение task group или template repository после открытия курса.
- [ ] Моковая реализация не моделирует конкурирующий course draft или конфликты публикации.
- [ ] Последовательность «создать → создать ещё → изменить перенесённые настройки → применить» проверена в реальном приложении.

### 2026-10-13T04:22:34Z · igormolchanov2000

По итогам [«Спроектировать настройку Task и Task Groups»](https://github.com/dsc-sgu/mm-frontend/issues/180#issuecomment-6138173472) «Создать ещё» переносит больше, чем сказано здесь:

- **переносит:** Task Group, максимальную Grade, Deadline уровня Task, Task Opening Time;
- **не переносит:** переопределения сроков и маски путей;
- **очищает:** название, условие, вложения и аннотацию; Task Key предлагается заново.

Этот тикет заменит тикет спецификации «Настройка Task и Task Groups», которую пишут после цепочки прототипов #181 → #190 → #191.
