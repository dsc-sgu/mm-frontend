# Показывать на Course Page неопубликованный черновик Teacher'а

## Source

[Спроектировать lifecycle Course Page Working Copy](https://github.com/dsc-sgu/mm-frontend/issues/118)

## What to build

Teacher, который ушёл из редактора с неопубликованным Course Draft Snapshot, видит на обычном Course Page опубликованную версию и может забыть о черновике. Нужно показывать у действия «Редактировать» пометку «Есть неопубликованный черновик», не захватывая Course Editing Lease.

## Acceptance criteria

- [ ] Наличие собственного черновика Teacher'а читается отдельной read-only операцией, которая не берёт lease и не создаёт черновик.
- [ ] Пометка видна только Teacher'у этого Course и только для его собственного черновика.
- [ ] Устаревший (stale) черновик помечается так же, как обычный: подробности Teacher увидит при входе в редактор.
- [ ] После публикации или удаления черновика пометка исчезает без перезагрузки страницы.
- [ ] Ошибка этой операции не блокирует Course Page и не показывает ложного «черновика нет»: пометка просто не отображается.

## Blocked by

- Read-only endpoint «есть ли у меня черновик этого Course» в backend, см. [«Реестр frontend-вопросов к backend API»](https://github.com/dsc-sgu/mm-frontend/issues/113).
- Slice «Сессия черновика» из решения [«Спроектировать lifecycle Course Page Working Copy»](https://github.com/dsc-sgu/mm-frontend/issues/118).
