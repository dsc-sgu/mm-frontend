# Прототип mm-181: в условии задания слэш-меню предлагает вставить задание

## Источник

Отзыв на прототип mm-181 в песочнице `prototype/sandbox` ([PR #244](https://github.com/dsc-sgu/mm-frontend/pull/244)), развёрнутая панель задания с редактором условия.

## Проблема

В развёрнутом редакторе условия задания слэш-меню «Добавить блок» содержит пункт «Задание — Новое задание: вставит блок задания…». Так в условие задания можно вставить блок задания, то есть задание внутри задания. Такой вложенности в модели нет.

Пункт берётся из общего слэш-меню редактора страницы курса: `src/features/course/features/page-edit/model/slash-menu.ts` (`id: 'task'`). Редактор условия переиспользует его без фильтрации.

## Что делает

- В редакторе условия задания нет пункта «Задание» и других блоков, допустимых только на странице курса.
- Блок задания не попадает в условие и обходными путями: вставкой из буфера обмена, перетаскиванием.

## Что решить

- Какие ещё блоки страницы курса недопустимы в условии задания. Набор лучше задать явно для каждого вида документа, а не вычитать из меню страницы курса.
- Перенести то же ограничение в настоящую реализацию, когда редактор условия задания появится вне прототипа.
