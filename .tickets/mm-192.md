# Фильтровать список попыток курса по подгруппе

## Источники

- Страница AnyType «Фронтенд MergeMinds», правки от 30.05.26, №15: «Андрей: хочется иметь фильтр по группам».

## Проблема

В списке попыток курса три фильтра: по заданию, по студентам и «Оценено» (`src/features/course/features/attempts/model/filters.ts`). Подгруппа видна в карточке попытки («Группа «…»»), но отобрать попытки по ней нельзя. Преподаватель, который после занятия проверяет одну подгруппу, выбирает её студентов по одному.

## Что делает

- В панели фильтров списка попыток курса появляется фильтр по подгруппе с множественным выбором, как у фильтров по заданию и по студентам.
- Выбранные подгруппы хранятся в параметрах строки запроса маршрута наравне с остальными фильтрами, поэтому ссылка на отфильтрованный список воспроизводима.
- Внутри фильтра выбранные подгруппы объединяются через «или», с остальными фильтрами — через «и».

## Что решить

- Сужается ли список вариантов фильтра по студентам до выбранных подгрупп.

## Связи

- mm-176 — управление подгруппами курса и приглашение студентов в нужную подгруппу: подгруппы плоские, у каждого студента ровно одна. Сейчас в `CourseAttemptStudent` подгруппа — это строки `group` и `subgroup` из моков, а фильтр должен опираться на модель mm-176.

## Вопросы к бэкенду

Фильтрует ли список попыток по подгруппе сам бэкенд. Добавить в реестр вопросов фронтенда к API бэкенда mm-113.
