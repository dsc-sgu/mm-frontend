# Добавить переход из quick-grading recovery к личному чату Teacher

## Контекст

Решение mm-114 «Определить роль bulk selection и quick grading в teacher workflow» вводит recovery panel для Grades, отклонённых из-за Review Lease или уже опубликованной конфликтующей Review. Recovery entry при наличии показывает Teacher, создавшего конфликт.

## Предпосылка

В MergeMinds реализованы личные сообщения и существует канонический способ открыть чат с конкретным User по его стабильной identity.

До появления этой capability issue не входит в implementation frontier. Когда появится основной implementation-ticket личных сообщений, связать этот issue нативной зависимостью `blocked by` с тем ticket.

## Желаемое поведение

Если recovery entry содержит стабильную identity конфликтующего Teacher, Teacher может открыть личный чат с ним непосредственно из recovery panel.

Переход должен:

- использовать стабильную User identity, а не отображаемое имя или username;
- открывать либо находить существующий direct chat согласно будущему контракту личных сообщений;
- сохранять recovery entry и введённый Grade при переходе;
- отсутствовать либо быть явно недоступным, если identity конфликтующего Teacher неизвестна;
- не делать личные сообщения обязательными для копирования, скачивания TXT, открытия individual review или другого recovery workflow.

## Не входит в этот issue

- проектирование и реализация личных сообщений;
- изменение concurrency semantics quick grading;
- автоматическая отправка сообщения без явного действия Teacher;
- добавление этой интеграции до появления стабильного direct-message contract.

## Источник решения

Полный контекст recovery panel, per-Attempt outcomes и конфликтов хранится в mm-114 «Определить роль bulk selection и quick grading в teacher workflow».
