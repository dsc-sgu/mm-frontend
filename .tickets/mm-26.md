# Grades table page layout

<img width="1271" height="831" alt="Image" src="mm-26/d73b374c.png" />

Многие преподаватели для своих курсов делают гугл-таблицы, в которых записывают баллы. Данное представление удобно, чтобы оценить, как много студентов близки или далеки к закрытию курса. Можно было бы сделать такое представление в MergeMinds.

По нажатию на ячейку также можно было бы открывать окошко для быстрого оценивания последней попытки студента. Или редактировать уже написанный отзыв. В этом окошке должен быть WYSIWYG-редактор и поле с указанием баллов (более подробное описание компонентов, которые могли бы быть полезны для такого редактора, описаны в #25).
