# Предупреждать об уходе с несинхронизированного course draft

## Parent

mm-63 «Согласовать карту реализованной frontend-системы»

## What to build

Защитить преподавателя от потери неподтверждённых изменений course draft: при внутренней навигации, reload или закрытии вкладки редактор запрашивает подтверждение, пока существует local working copy, не синхронизированная с текущим владельцем persistence.

## Acceptance criteria

- [ ] SPA navigation позволяет остаться или подтвердить уход при несинхронизированных изменениях.
- [ ] Reload и закрытие вкладки используют browser-native beforeunload warning.
- [ ] Clean, successfully saved и explicitly discarded состояния не показывают предупреждение.
- [ ] Успешное сохранение не оставляет устаревший navigation blocker.
- [ ] Reusable interface выражен через hasUnsyncedChanges и не привязан навсегда к текущему local-only isDirty.
- [ ] Реализация не полагается на ненадёжный async-save во время unload.
- [ ] Lint и build проходят.

- Reload и закрытие вкладки используют `beforeunload`; асинхронное сохранение во время unload не используется.
