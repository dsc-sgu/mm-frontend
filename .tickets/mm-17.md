# Course home page edit mode layout

Режим редактирования для главной страницы курса. На ней можно редактировать:
1. Название курса
2. slug курса
3. Описание курса
4. Цвет курса
5. Иконку курса
6. Контент курса

При этом визуально должно быть сразу видно, как это будет выглядеть. И сами изменения должны делаться как бы in-place.

На Moodle при перемещении элементов на странице изменения применяются сразу. Это нехорошо, потому что сторонние наблюдатели могут видеть сырые промежуточные состояния. Нужно сделать отдельную кнопку "применить", чтобы одним кликом батчём применять все сделанные изменения. Механику черновиков здесь делать не будем, это на отдельный issue.

Из каких блоков состоит контент главной страницы курса:
1. Параграфы (в рамках их может быть жирный, курсивный текст, внешние и внутренние ссылки)
2. Заголовки
3. Цитаты
4. Нумерованные списки
5. Ненумернованные списки
6. Спойлеры
7. Блоки кода
8. Картинки
9. Файлы
10. Задания

При этом блоки картинок, видео, файлов и заданий работают так, что сами эти вещи хранятся внутри курса, а блоки главной страницы как бы ссылаются на них.

Редакторование главной страницы должно быть похоже на то, как это сделано в Notion/AnyType. Для этого даже есть готовые библиотеки.

Порядок блоков надо определять через лексоранг. Бекенд может его вернуть, но в целом лексоранг по большей мере будет жить на бекенде, поэтому при создании моков будем исходить из этого.
