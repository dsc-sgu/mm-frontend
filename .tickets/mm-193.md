# Сортировать список попыток курса по времени отправки и фильтровать по периоду

## Источники

- Страница AnyType «Разбор состояния фронтенда MergeMinds на 6.06.2026», №1: «Пока не хватает фильтра на дату или хотя бы сортировки по дате, частый кейс проверять работы, которые давно не проверялись».
- Страница AnyType «Ругаюсь на Moodle»: сортировка по дате последней попытки.

## Проблема

В списке попыток курса нет ни сортировки, ни фильтра по времени. Порядок задаёт источник данных: сейчас это порядок, в котором их сгенерировал мок. Преподаватель не может поднять наверх попытки, которые дольше всех ждут проверки, и не может ограничить список, например, последней неделей.

## Что делает

- Сортировка по времени отправки попытки: сначала старые (дольше ждут проверки) или сначала новые.
- Фильтр по периоду отправки: «с» и «по».
- Сортировка и период хранятся в параметрах строки запроса маршрута, как остальные фильтры.
- Время подписано часовым поясом, как в mm-182.

## Что решить

- Сортировка по умолчанию. Вместе с фильтром «Не оценено» естественна очередь проверки: сначала старые.
- Нужна ли сортировка по времени последней версии проверки.
- Ввод дат: тот же элемент ввода, что у дедлайна в mm-42.

## Вопросы к бэкенду

Сортировка и фильтр по периоду на стороне бэкенда, чтобы они работали вместе с пагинацией. Добавить в реестр вопросов фронтенда к API бэкенда mm-113.
