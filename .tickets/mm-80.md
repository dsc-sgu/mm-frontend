# Перевести teacher attempts и quick grading flow на общий mock backend

## Parent

[Перевести frontend с RAM-моков на fetch и MSW](https://github.com/dsc-sgu/mm-frontend/issues/73)

## What to build

Перевести teacher attempts flow на общий mock backend: преподаватель курса фильтрует студенческие попытки, получает review-lock updates и сохраняет одиночные или массовые оценки через HTTP. Изменённая оценка должна читаться из той же канонической попытки как в teacher attempts list, так и в student task history.

## Acceptance criteria

- [ ] Teacher attempts list загружается через fetch/MSW и поддерживает существующие filters.
- [ ] Course membership определяет доступ преподавателя к списку попыток.
- [ ] Quick grading и массовая максимальная оценка сохраняются через HTTP mutations.
- [ ] Grade хранится на канонической попытке и согласованно видна в teacher и student representations после refetch.
- [ ] Review-lock updates обслуживаются mock backend и не создают отдельную копию attempts state.
- [ ] Attempts feature больше не импортирует собственный stateful RAM-мок.
- [ ] Lint и build проходят.
