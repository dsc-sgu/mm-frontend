# REV7.3: Продолжать Review editor при зависании и закрытии вкладки и при выходе из аккаунта

Часть epic mm-218 «Review».

Review editor продолжает работу, когда пишущая вкладка зависла, закрылась или User вышел из аккаунта. Зависшая вкладка не перезаписывает правки после пробуждения, а Working Copy не достаётся другому User.

### Делает

**Силовая смена.**
- Если пишущая вкладка молчит 3 с после «Продолжить здесь», копия продолжает сама, без второго нажатия.
- Если вкладка ответила `handoff-accepted` и ждёт свой запрос, срок — таймаут запроса плюс 3 с.
- Продолжить силой может только вкладка с живой копией.
- Порядок: сначала счётчик в localStorage, потом `steal` lock'а.

**Проснувшаяся бывшая пишущая вкладка.**
- Сверяет счётчик раньше, чем узнаёт о потере lock. Её просроченные heartbeat и повтор публикации ничего не отправляют.
- Первое нажатие в ней не применяется. Она становится копией.

**Вкладка без живой копии** (открыта, когда пишущая уже молчит) показывает «Редактор открыт в другой вкладке, она не отвечает — перейдите в неё» и становится копией, когда пишущая оживает.

**Добровольная смена.** Пишущая вкладка держит lock, пока получатель не заберёт его `steal`. Если получатель не забрал lock за 1 с, роль возвращается.

**Уход.** Предупреждение об уходе с несохранённой Working Copy нужно, только если совместимой живой копии нет.

**Выход из аккаунта.**
- Содержимое во всех вкладках скрыто экраном «Вы вышли из аккаунта». Working Copy держится в памяти, закрытие вкладки предупреждает.
- Вход тем же User продолжает работу. Lease прежней сессии берётся перехватом тем же User.
- Вход другим User удаляет Working Copy прежнего.

**bfcache.**
- `pagehide` — уход: lock и канал отпускаются, копия продолжает.
- При `pageshow` с `persisted` вкладка продолжает со своей Working Copy, только если запись о пишущей вкладке не менялась. Иначе выбрасывает её и подключается заново.

**Непроверенные допущения о движках** из mm-132 проверяются здесь:
- читается ли счётчик в localStorage синхронно и в актуальном значении сразу после разморозки;
- замораживаются ли отдельные фоновые вкладки в Firefox и Safari;
- блокирует ли удерживаемый Web Lock попадание в bfcache.

Результаты записываются в PR.

### Не входит

- TAB-03 (силовая смена с таймером автосохранения), TAB-07 и TAB-09 — DRF4.
- Восстановление Working Copy из браузера после закрытия всех вкладок — mm-125.
