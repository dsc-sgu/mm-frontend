# DOC3: Сохранять документ без потерь и проверять вставленное содержимое

## Цель

Разделить headless-профиль Plate и React-привязки. Профиль создаёт только сохраняемые узлы; fromPlate(toPlate(doc)) = doc. Вставка проходит DOMPurify, преобразование и нормализацию с сохранением текста. Отделить unsupported-content от исправимых отклонений. clipboard auto-read разрешён только в Chromium; вставленный Markdown остаётся текстом.

## Удаляет или заменяет

Потерю содержимого при преобразовании документа, неподдерживаемые узлы профиля, обход границы доверия при вставке.

## Принятое решение и границы

Владелец подтвердил frontend-first подход: существующий API-слой бэкенда заменяется контрактами, определёнными потребностями фронтенда. Модель черновиков блоков, публикации со слиянием и чекпоинтов согласована. Ожидание старого API не блокирует этап. HTTP-формы и исходы операции закрепляются в схемах, MSW и тестах; вопросы о реализации и оставшиеся ограничения фиксируются в mm-113.

Перед реализацией прочитать `docs/agents/remote-data.md`, актуальный `CONTEXT.md` и связанные ADR. Устаревшие положения ADR 0002 и ADR 0004 о брони редактирования курса заменяются решением mm-286; бронь проверки сохраняется. Изменения доменной документации учитывает mm-286.

Новая архитектура не требует переименования каталогов из mm-292 заранее: использовать текущие пути с теми же владельцами поведения. Не выделять отдельное «чистое ядро». Этап выполняется заменой за один шаг без второго временного пути данных.

## Проверяемое поведение

- `DOC-01`: Закон round-trip `fromPlate(toPlate(doc)) = doc` — property-тест на генераторе нормализованных документов.
- `DOC-11`: Редактор с неподдерживаемым содержимым не открывается: `unsupported-content` с предложением обновить приложение.
- `DOC-16`: Вставка в страницу курса: внешний HTML → DOMPurify → конвертер → нормализатор; текст сохранён; профиль не создаёт того, что документ не сможет сохранить.
- `DOC-23`: Markdown при наборе создаёт только узлы профиля: `#`/`##`/`###` → заголовок, `>` → цитата, `- ` → маркированный список, `1. ` → нумерованный (`3. ` остаётся текстом, #74), три backtick → блок кода, `**`, `*`, `` ` `` → жирный, курсив, код; `[t](url)` и вставка URL дают ссылку только с разрешённой схемой; внутри блока кода ничего не преобразуется.
- `DOC-17`: Ограничения профиля: Tab вне списка ничего не делает; в цитате Shift+Enter — перенос строки, Enter на пустой строке — выход в обычный абзац.

Property-тесты round-trip и канонизации через fast-check в Node с воспроизводимым seed. Проверить headless createSlateEditor при реализации; не требовать внутренней переработки DOC4–DOC5 для HTTP-интеграции.
