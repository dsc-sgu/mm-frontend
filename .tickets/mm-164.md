# Попытки части студентов из списка не открываются: редирект на страницу курса

### Проблема

В dev на RAM-моках `mit-teacher` открывает «Попытки» курса «Современные информационные технологии» и выбирает попытку, например, студента `student-07`. Вместо страницы проверки открывается страница курса. Пример: `/courses/modern-information-technologies/tasks/1/attempts/student-07/1/review`. Попытки `student` и `bob` открываются нормально.

### Причина

Два RAM-мока не согласованы.

- `features/course/features/attempts/api/mock.ts` генерирует для каждого курса 60 студентов: `student`, `alice`, `bob`, `student-04` … `student-60`.
- `features/course/features/access/api/mock.ts` знает в курсе СИТ только `student`, `mit-student` и `bob`.

Для Teacher route `…/attempts/$studentUsername/$attemptId` вызывает `requireKnownCourseStudent` из `features/course/routing/guards.ts`. Если username нет в `studentUsernames` мока доступа, guard перенаправляет на страницу курса. Мок ревью (`attempt-review/api/mock.ts`) берёт попытку из мока списка, поэтому данные для этих попыток есть.

С [PR #161](https://github.com/dsc-sgu/mm-frontend/pull/161) не связано: он не меняет ни guard, ни эти моки.

### Делает

Согласовывает RAM-моки: каждый Student, у которого есть попытки в моке списка, становится Student'ом курса в моке доступа. Существующие участники курсов, включая `mit-teacher` как Student'а других курсов, сохраняются. Мок-файлы могут импортировать друг друга, ESLint это разрешает.

### Не входит

- Удаление клиентской проверки состава курса (`studentUsernames`, `requireKnownCourseStudent`) — это ACC1/ACC2 по решению mm-115 «Спроектировать Course access vertical и identity seam».
- Перевод попыток и ревью на MSW с мирами `world:attempts-list` и `world:review` — это ATT1/REV2.

Тикет даёт временную согласованность RAM-моков до этих slices.

### Готово, когда

- Под `mit-teacher` из списка попыток курса СИТ открывается страница проверки любой попытки, включая `student-07`.
- Для username, которого нет в курсе (например, `/courses/modern-information-technologies/tasks/1/attempts/nobody/1/review`), редирект на страницу курса сохраняется.
- `bun run lint` и `bun run build` проходят.
