# W0-5: Подключить Prettier к ESLint через prettierRecommended

### Делает

- В `eslint.config.js` подключается `eslint-plugin-prettier/recommended` последним элементом config array.
- Preset заменяет ручную регистрацию plugin `prettier` и ручное правило `prettier/prettier`.
- Зависимости остаются: `eslint-plugin-prettier`, `eslint-config-prettier` (preset через него отключает конфликтующие правила), `prettier`, `prettier-plugin-tailwindcss` и текущий `.prettierrc`.

### Удаляет

Ручную интеграцию Prettier в ESLint config.

### Готово, когда

- `bun run lint` по-прежнему сообщает о форматировании как об ошибке ESLint. Проверено намеренно испорченным файлом.
- `bun run format` остаётся исправляющей командой.
- Lint и build проходят.
