# Запрототипировать управление Task Groups

## Question

Как Teacher управляет Task Groups, если на Course Page их не видно?

## Входы

- **Решения mm-180:**
  - Task Group существует, только пока в ней есть Task. Она появляется вместе с первой Task (её создают в поле Task Group панели) и исчезает с последней.
  - В панели под полем Task Group — раздел группы:
    - название;
    - Task Group Key;
    - адрес шаблонного репозитория и его состояние;
    - список Task группы с выделенной текущей; порядок меняется перетаскиванием.
  - Перенос Task в другую группу — только пока Course `draft`:
    - через поле Task Group; Task встаёт в конец новой группы;
    - если её Task Key уже занят в новой группе, ошибка с предложением свободного ключа;
    - опустевшая группа исчезает при публикации, а если у неё есть шаблон, перед этим предупреждение.
  - Порядок Task в группе задаётся явно, переставлять можно только пока Course `draft`. После открытия меняется только название группы.
  - Шаблон наполняется через git push. Пустой шаблон допустим. После открытия шаблон не меняется.
- **Вопрос Q5 из mm-180, решён предварительно:** новая Task по умолчанию попадает в свою новую группу, а «Создать ещё» переносит группу предыдущей Task. Пересмотреть здесь. Возможно, в выбранном UI этот вопрос вообще не возникнет.
- **mm-40 закрыт.** Список Task для Teacher сравнивается здесь как вариант «обзора».
- **Факты backend и расхождения** — mm-113, пункты о заданиях и цепочках заданий в уровнях 1 и 3. Там же: в [«Ezhkin-Kot/fixes»](https://github.com/dsc-sgu/mm-backend/pull/172) шаблон заливается только ZIP.

## Что сравнить

- Переключатель `?groups=panel|overview`:
  - `panel` — только раздел группы в панели;
  - `overview` — тот же раздел плюс экран-обзор: все группы, их Task по порядку, ключи и состояние шаблонов.
- Куда новая Task попадает по умолчанию (Q5).
- Как показать адрес шаблона и его состояние: пуст или последний коммит.
- Перестановка Task и перенос между группами: в разделе группы и в обзоре.
- Открытый Course: что стало только для чтения и как это объяснено.

## Устройство

- **Та же песочница, что у mm-181:** ветка `prototype/task-and-deadline-settings`, тот же fixture и плавающая панель вариантов. Строится поверх mm-181, где группа в панели пока упрощённое поле.
- **Fixture:** 2–3 Task Groups, например «Лабораторные», «Домашние», «Курсовая»; у одной шаблон пуст.
