# Добавить жёсткий срок сдачи (cut-off) для Task

## Source

- [«Edit deadlines layout»](https://github.com/dsc-sgu/mm-frontend/issues/42): в MVP Deadline только мягкий. Он не закрывает Task, а Attempt после него принимается и считается опоздавшей (`CONTEXT.md`, Deadline). Жёсткий срок вынесен сюда, в backlog.

## Проблема

Иногда Teacher'у нужен момент, после которого Attempt по Task больше не принимается: например, конец зачётной недели. В Moodle Assignment это cut-off date рядом с due date. Сейчас такого понятия нет ни во frontend, ни на backend: у `tasks` есть только `available_at` и `deadline_at`.

## Почему не сейчас

- Сдача идёт через Git: push в последние секунды и сетевые задержки делают жёсткую границу спорной.
- Cut-off добавляет Task состояние «закрыта для этого Student». Оно пересекается со Student Task Access и с ещё не выбранным критерием progression ([«Согласовать критерий завершения задания и открытия следующего»](https://github.com/dsc-sgu/mm-frontend/issues/110)).

## Что решить

- Задаётся ли cut-off на тех же уровнях, что Deadline: у Task, Deadline Override для Student Group и для Student, с тем же правилом старшинства.
- Должен ли cut-off быть не раньше Effective Deadline.
- По какому моменту судит backend: по времени push или по времени, когда backend получил Attempt.
- Что видит Student до и после cut-off.
- Вопрос к backend добавить в [«Реестр frontend-вопросов к backend API»](https://github.com/dsc-sgu/mm-frontend/issues/113).
