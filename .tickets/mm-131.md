# Подсветка синтаксиса в code block редактора Course Page

## Контекст

В read-only code block Course Page подсвечивается Shiki (`features/code-block`), а в редакторе это обычный `<pre>` без подсветки. По решению mm-119 «Спроектировать structured-document seam Course Page» parity editor ↔ read-only сейчас требует совпадения chrome code block: рамки, header, шрифта и фона. Цвета токенов из parity-контракта исключены, а подсветка в редакторе вынесена сюда как новая функция.

## What to build

Подсвечивать код в code block редактора теми же темами и грамматиками, что и в read-only, не ломая ввод, выделение и undo.

## Acceptance criteria

- [ ] Подсветка в редакторе визуально совпадает с read-only для поддерживаемых языков.
- [ ] Ввод, выделение, undo/redo и смена языка не теряют курсор и не тормозят на типичных фрагментах.
- [ ] Загрузка грамматик и тем не блокирует открытие редактора; ошибка загрузки оставляет код читаемым без подсветки.
- [ ] Parity-тест computed styles дополнен цветами токенов.

## Blocked by
