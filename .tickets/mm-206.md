# Добавить блок видео на страницу курса

## Источники

- Страница AnyType «Фронтенд MergeMinds», «Что нужно уметь редактировать в курсе»: «Картинки, видео и файлы курса», в списке блоков — «Видео».

## Проблема

Блоки страницы курса: абзац, заголовок, цитата, список, спойлер, код, картинка, файлы и блок задания (`src/features/course/features/page-edit/model/block-operations.ts`). Видео преподаватель может дать только ссылкой в тексте.

## Что решить

- Источник видео:
  - загрузка файла: лимиты размера, хранение;
  - встраивание по ссылке (YouTube, RuTube, VK Видео и другие): `iframe`, политика безопасности, приватность;
  - и то и другое.
- Проигрыватель: `<video>` для загруженных файлов, `iframe` для встраиваемых. Превью и подпись.
- Новый тип блока в доменном документе страницы курса (ADR 0003): `data` блока и его версия.
- Вопросы к бэкенду (тип блока, хранение файлов) добавить в реестр вопросов фронтенда к API бэкенда mm-113.
