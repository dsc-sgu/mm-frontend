# Добавить видео-блок на Course Page

## Source

- Страница AnyType «Фронтенд MergeMinds», «Что нужно уметь редактировать в курсе»: «Картинки, видео и файлы курса», в списке блоков — «Видео».

## Проблема

Блоки Course Page: абзац, заголовок, цитата, список, спойлер, код, картинка, файлы и Task Reference (`src/features/course/features/page-edit/model/block-operations.ts`). Видео Teacher может дать только ссылкой в тексте.

## Что решить

- Источник видео:
  - загрузка файла: лимиты размера, хранение;
  - встраивание по ссылке (YouTube, RuTube, VK Видео и другие): `iframe`, политика безопасности, приватность;
  - и то и другое.
- Проигрыватель: `<video>` для загруженных файлов, `iframe` для встраиваемых. Превью и подпись.
- Новый тип блока в доменном документе Course Page (ADR 0003): `data` блока и его версия.
- Вопросы к backend (тип блока, хранение файлов) добавить в [«Реестр frontend-вопросов к backend API»](https://github.com/dsc-sgu/mm-frontend/issues/113).
