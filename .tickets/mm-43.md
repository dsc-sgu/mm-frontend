# Routes architecture and placeholders

| URL                                                                        | Назначение                           | Доступ                                                              |
| -------------------------------------------------------------------------- | ------------------------------------ | ------------------------------------------------------------------- |
| `/`                                                                        | Дашборд                              | Все авторизованные пользователи                                     |
| `/courses/[course-slug]`                                                   | Корневая страница курса              | Участники курса                                                     |
| `/courses/[course-slug]/repositories`                                      | Список репозиториев студентов        | Только преподаватель курса                                          |
| `/courses/[course-slug]/repositories/[student-username]`                   | Репозиторий конкретного студента     | Студент — только свой, преподаватель — репозитории студентов        |
| `/courses/[course-slug]/repositories/[student-username]/commits`           | Список коммитов репозитория          | Студент — только свой, преподаватель — репозитории студентов        |
| `/courses/[course-slug]/repositories/[student-username]/commits/123`       | Конкретный коммит                    | Студент — только свой, преподаватель — репозитории студентов        |
| `/courses/[course-slug]/tasks/[task-id]`                                   | Корневая страница задания            | Участники курса                                                     |
| `/courses/[course-slug]/tasks/[task-id]/edit`                              | Редактирование задания               | Только преподаватель курса                                          |
| `/courses/[course-slug]/tasks/[task-id]/attempts/[student-username]/[attempt-id]`             | Diff попытки                         | Студент — только свои попытки, преподаватель — попытки студентов    |
| `/courses/[course-slug]/tasks/[task-id]/attempts/[student-username]/[attempt-id]/review`      | Оценка попытки                       | Только преподаватель курса                                          |
| `/courses/[course-slug]/journal`                                           | Журнал в виде excel-like таблицы     | Обычно преподаватель; read-only для студентов                       |
| `/courses/[course-slug]/edit`                                              | Редактирование курса                 | Только преподаватель курса                                          |
| `/courses/[course-slug]/stats`                                             | Аналитика                            | Участники курса                                                     |
| `/courses/[course-slug]/files`                                             | Файлы курса                          | Только преподаватель курса                                          |


- `[course-slug]` — человекочитаемое имя курса для URLа, содержит латинские символы в нижнем регистре, цифры от 0 до 9 и дефисы
- `[student-username]` — имя пользователя, содержит латинские символы в нижнем регистре, цифры от 0 до 9 и дефисы
- `[task-id]` — ID задачи, является целым числом
- `[attempt-id]` — ID попытки/её порядковый номер, является целым числом, является уникальным в рамках пары student-username и task-id, то есть является частью композитного ключа из трёх идентификаторов

Здесь пока что не учтено, что вместо student-username может быть participant, что задание может сдавать не только один человек, но и много людей. Но думаю, это не сильно страшно.
