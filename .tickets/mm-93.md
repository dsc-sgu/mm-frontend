# Синхронизировать course metadata и resources

## Parent

mm-78 «Перевести course dashboard и редактирование курса на общий mock backend»

## What to build

Сохранять course metadata, presentation fields и resources через согласованную backend boundary и восстанавливать их вместе с editing session без преждевременного изменения student-facing published course.

## Acceptance criteria

- [ ] Все редактируемые metadata и resources имеют однозначного server owner.
- [ ] Изменения проходят через fetch/MSW и observable sync lifecycle.
- [ ] Reload restored session возвращает подтверждённые значения.
- [ ] Slug change следует согласованной identity/navigation semantics и не теряет draft.
- [ ] Failed mutation сохраняет working copy и даёт повторить синхронизацию.
- [ ] Student-facing reads меняются только согласно publish boundary.
- [ ] Lint и build проходят.
