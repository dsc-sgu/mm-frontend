# Выбирать, с чем сравнивать Attempt в Attempt review

## Source

- Страница AnyType «MergeMinds: задания, task-группы, шаблоны и репозитории курса» в «Всё идёт по плану», §20 «Diff попытки»: «Всегда показывать base и target… Базу можно переключать. Показывать commits между состояниями и фильтр: [Все] [Студент] [Преподаватель/платформа]».

## Проблема

Attempt review всегда сравнивает Attempt с одной базой: в шапке «Сравнение с попыткой #N» или «Сравнение с пустой базой» (`src/features/course/features/attempt-review/ui/header.tsx`). Teacher не может:

- сравнить Attempt mm-3 с Attempt mm-1, то есть увидеть всё, что изменилось после первой Review;
- сравнить Attempt с шаблонным репозиторием Task Group;
- увидеть commits между базой и Attempt.

## Расхождение с решением

mm-116 «Спроектировать Review → Grade → Student result vertical»: «Baseline выбирает backend и описывает его в manifest… Frontend показывает „Сравнение с …“ и адресует материал только `AttemptId`». Этот тикет предлагает сохранить baseline от backend по умолчанию и дать Teacher'у выбрать другую базу. Для этого контракт должен принимать пару «Attempt и база». В [«Ezhkin-Kot/fixes»](https://github.com/dsc-sgu/mm-backend/pull/172) есть `GET /attempts/diff?id1&id2`, где пару выбирает клиент.

## Что решить

- Какие базы доступны: любая предыдущая Attempt той же Task, Attempt предыдущей Task в Task Group, шаблон, пустое дерево.
- Что происходит с Line Comment Threads при другой базе. Root comment привязан к стороне diff и строкам относительно baseline. Возможно, с другой базой экран только для чтения.
- Показывать ли список commits между базой и Attempt. Фильтр «Студент / платформа» имеет смысл, только если платформа сама коммитит в репозиторий Student. После mm-180 шаблон после открытия Course не меняется, поэтому таких commits пока нет.
