# W0-4: Строить cn() только на tailwind-merge

### Делает

`cn()` строится только на `tailwind-merge`:

```ts
import { twMerge, type ClassNameValue } from 'tailwind-merge';

export function cn(...inputs: ClassNameValue[]) {
  return twMerge(...inputs);
}
```

`twMerge` сам принимает строки, falsy-значения и вложенные массивы. Object-map синтаксис (`{ active: condition }`) он не поддерживает. Аудит не нашёл его ни в одном из 287 вызовов `cn()`. Если такой вызов появился позже, его ловит `tsc`, и вызов переписывается на условное выражение.

### Удаляет

Зависимость `clsx`. Object-map API в `cn()` не возвращается без реальной потребности.

### Готово, когда

Lint и build проходят.
