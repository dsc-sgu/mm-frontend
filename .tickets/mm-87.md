# Предупреждать об уходе с несохранённого attempt review

## Parent

mm-63 «Согласовать карту реализованной frontend-системы»

## What to build

Применить общий unsynced-change guard к editable attempt review, чтобы преподаватель не потерял score, overall feedback, line-comment drafts или другие несохранённые изменения при смене попытки, навигации, reload или закрытии вкладки.

## Acceptance criteria

- [ ] Editable review с несохранёнными изменениями блокирует SPA navigation и browser unload.
- [ ] Переход к другой попытке требует подтверждения.
- [ ] После успешного save или явного discard предупреждение исчезает.
- [ ] Readonly review и review без локальных изменений не блокируют уход.
- [ ] Новые line-comment drafts учитываются как несохранённая работа.
- [ ] Используется общий guard contract из course editor.
- [ ] Lint и build проходят.

## Связь с Review vertical

Решение mm-116 «Спроектировать Review → Grade → Student result vertical» включает этот guard в slice 6 «Ядро Review editor» и уточняет его:

- Несохранённой считается Review Working Copy, отличающаяся от последней Review Revision: Grade, Overall Feedback и собственные root comments. Replies в Working Copy больше не входят, они публикуются сразу.
- Подтверждения требуют навигация по приложению, переключение Attempt через selector, reload и закрытие вкладки.
- В состоянии `publication-unconfirmed` уход предупреждает «Публикация не подтверждена».
- Review Lease снимается только после подтверждения ухода.
- Attempt page (просмотр) и Review editor без изменений уход не блокируют.
- Термины «score» и «line-comment drafts» в этом issue соответствуют Grade и собственным root comments в Working Copy.
