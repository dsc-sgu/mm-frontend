# Восстанавливать неопубликованную Review Working Copy из браузера

## Source

[Спроектировать Review → Grade → Student result vertical](https://github.com/dsc-sgu/mm-frontend/issues/116)

## What to build

После MVP добавить browser-local recovery для неопубликованной Review Working Copy в Review editor. Опубликованная Review Revision остаётся authoritative state; локальная запись является только кандидатом на восстановление изменений Teacher'а, которые ещё не были опубликованы. Решение по vertical уже делает Working Copy сериализуемыми данными с пометкой `attemptId + baseRevision`, а восстановление использует ту же панель «Неопубликованные изменения», что и потеря lease или конфликт revision.

## Acceptance criteria

- [ ] Неопубликованная Working Copy (Grade, Overall Feedback, собственные root comments с привязкой к строкам) сохраняется локально с identity User, Attempt и `baseRevision`.
- [ ] После reload восстановление предлагается только после загрузки authoritative Review Revision и проверки совместимости записи с ней.
- [ ] Совместимая запись (`baseRevision` совпадает с последней revision) не применяется автоматически: Teacher явно выбирает восстановить её или удалить.
- [ ] Если revision изменилась, элементы записи переносятся только вручную через панель «Неопубликованные изменения»; автоматического merge нет.
- [ ] Запись не восстанавливается в обход Review Lease: редактировать восстановленное можно только при удерживаемом lease.
- [ ] Успешная публикация, явный discard и подтверждённый уход очищают связанную запись; запись в состоянии `publication-unconfirmed` не удаляется до известного исхода.
- [ ] Logout/session replacement не позволяет следующему User восстановить чужую Working Copy (общие компьютеры учебных классов).
- [ ] Отказ или переполнение local storage не блокирует Review editor; UI не сообщает ложный success восстановления.
- [ ] Поведение нескольких вкладок одного Teacher'а согласовано с lease на сессию Review editor.
- [ ] Сценарии crash/reload, изменившейся revision, explicit restore/discard и cleanup проверены через наблюдаемое поведение.

## Blocked by

- Реализация slice «Ядро Review editor» из [«Спроектировать Review → Grade → Student result vertical»](https://github.com/dsc-sgu/mm-frontend/issues/116).
- Исследование [«Исследовать React abstraction для persistent browser preferences»](https://github.com/dsc-sgu/mm-frontend/issues/97) либо отдельное решение об abstraction для browser storage.
- Согласованный backend contract Review Revision и номеров revision.
