# REV4: Писать и показывать текст проверки на Plate без HTML в модели

Часть эпика mm-218. Перед началом прочитать [`docs/agents/remote-data.md`](https://github.com/dsc-sgu/mm-frontend/blob/main/docs/agents/remote-data.md) (обязательно по `AGENTS.md`).

Общий отзыв, комментарии преподавателя и ответы пишутся и показываются на Plate по `ReviewTextDocument`. HTML нет ни в модели, ни в моках, ни в режиме только для чтения. Ссылка вставляется через диалог.

**Ждёт DOC1** из эпика «Редактирование курса»: общий интерфейс форматированного текста (`course/ui/rich-text`) и политику ссылок (`course/model/links.ts`). Эпик ещё не создан, связь добавится при его создании.

### Делает

**`ReviewTextDocument`** — собственная версионируемая схема проекта `{ version: 1, children: ReviewTextBlock[] }` в модели модуля `review`. DTO-схемы операций проверки её переиспользуют.
- Профиль v1:
  - абзац и жёсткий перенос строки;
  - полужирный, курсив, зачёркнутый, инлайн-код;
  - цитата;
  - вложенные нумерованные и маркированные списки без произвольного start;
  - простой блок кода без языка;
  - ссылки.
- Заголовки, горизонтальные линии и изображения не поддерживаются.
- Схема строга к version, дискриминантам узлов и marks, полям и URL. Неизвестное делает ответ `invalid-response`, содержимое не урезается молча. Переходы между версиями схемы — явные чистые миграции.
- Ссылки валидирует общая политика DOC1.

**Пустота.**
- Очищенный общий отзыв — `null`; пустой абзац допустим только в локальном черновике редактора.
- Комментарий преподавателя и ответ сохраняются, только если они непустые после нормализации пробелов и жёстких переносов.

**Редактор текста проверки и режим только для чтения.**
- Редактирование и режим только для чтения используют один профиль Plate.
- Режим только для чтения строит React-элементы из провалидированных узлов, без `dangerouslySetInnerHTML`.
- Ссылка от корня сайта открывается роутером в текущей вкладке, внешняя — в новой с `rel="noopener noreferrer"`.

**Диалог ссылки** вместо `window.prompt`: валидация по политике ссылок, ошибка у поля, возврат фокуса в редактор текста проверки. Кнопка картинки удаляется.

**Вставка — единственная граница доверия для HTML:** DOMPurify → конвертер в профиль v1 → нормализатор. Script, style, изображения и заголовки удаляются с сохранением текста. Вставленный простой текст остаётся простым текстом.

**Фикстуры** мок-бэкенда разово конвертируются в v1 без потери содержания.

### Удаляет

- TipTap и все `@tiptap/*`.
- HTML-поля в модели, DTO и фикстурах, санитизацию HTML в режиме только для чтения.
- `window.prompt` для ссылки и картинки.

### Не входит

- Ответы как отдельные операции — REV5.
- Изображения — только вместе с отдельным контрактом для управляемых файлов (managed assets).
- Двойное чтение старого и нового формата, запасной показ старого HTML, постоянный адаптер HTML→Plate.
