# Плавно переключать тему

## Источники

- Страница AnyType «Фронтенд MergeMinds», неструктурированные идеи, №8: «Возможно я бы хотел более плавное переключение темы».

## Проблема

Кнопка темы (`ToggleThemeBtn` в `src/app/header/ui/header.tsx`) переключает класс `dark` на `<html>`. Все цвета меняются в один кадр, и на больших экранах, например в diff попытки, это выглядит как вспышка.

## Что делает

- Смена темы анимируется через View Transitions API (`document.startViewTransition`): плавная смена или раскрытие от кнопки. Где API нет, тема меняется мгновенно, как сейчас.
- При `prefers-reduced-motion: reduce` анимации нет.
- Diff (`themeType` через `useHtmlThemeType`) переключается вместе со страницей, без кадра в старой теме.
- Анимация не вешает `transition` на все элементы страницы.
