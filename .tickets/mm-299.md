# Эпик: Список попыток курса и быстрое оценивание на общем API

## Цель

Заменить локальные агрегаты списка попыток общими попытками и версиями проверки через Fetch, Valibot и MSW. Этапы ATT1–ATT6 — дочерние тикеты: чтение, фильтры, жизненный цикл, переходы, согласованность и быстрое оценивание.

## Границы

Контракты и жизненный цикл — P1; переработка фильтров и раскладок — P2. Существующий mm-45 сохраняет продуктовую цель уплотнения списка и не дублирует реализацию ATT4. Общий отзыв первой проверки, частичные результаты публикации и выход из режима определены mm-114 и mm-121. API проектирует фронтенд, операции проверки остаются у review.

## Готово, когда

Вся вертикаль получает данные через общий мок-бэкенд и операции владельцев; оценки согласованы со страницей попытки; быстрый режим не создаёт второй путь публикации. Источники — mm-69, mm-117, mm-114, mm-121.
