# Перевести course dashboard и редактирование курса на общий mock backend

## Parent

mm-73 «Перевести frontend с RAM-моков на fetch и MSW»

## What to build

Перевести dashboard, course access, course page, deadlines и редактирование курса на HTTP/MSW поверх общего канонического mock backend state. Пользователь должен открыть курс, изменить его содержимое или slug и увидеть согласованный результат во всех связанных представлениях без ручной синхронизации независимых response stores.

## Acceptance criteria

- [ ] Course list, course access, course page и deadlines загружаются через fetch-клиенты и MSW handlers.
- [ ] Courses, memberships, pages, tasks и связанные deadlines происходят из одного согласованного backend state.
- [ ] Сохранение страницы курса изменяет каноническое состояние, а последующие reads возвращают обновлённые данные.
- [ ] Смена slug согласованно отражается в course list, course access и course page.
- [ ] Deadlines детерминированы состоянием backend и не меняются случайно при refetch.
- [ ] Feature query/mutation modules не импортируют реализацию mock backend.
- [ ] Lint и build проходят.
