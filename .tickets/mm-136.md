# Обновить крупные версии инструментов: ESLint, Vite, TypeScript, Globals, Lucide

## Источники

- mm-71 (аудит зависимостей и конкурирующих библиотек), дополнение «Ревизия доступных версий», когорта 9 (cohort 9).
- mm-69 (последовательность подготовки и выполнения рефакторинга): крупные обновления инструментов вынесены из последовательности рефакторинга в бэклог.

## Что сделать

Обновить крупные версии инструментов. Каждое обновление идёт своим PR, со своими заметками о миграции и с проверкой: `bun run lint`, `bun run build` и все наборы тестов, которые к тому моменту есть в CI, проходят.

- [ ] ESLint 9 → 10 вместе с `@eslint/js` 9 → 10.
- [ ] Vite 7 → 8 вместе с `@vitejs/plugin-react` 5 → 6.
- [ ] TypeScript 5.9 → 7.
- [ ] Globals 16 → 17.
- [ ] Lucide 0.x → 1.x: проверить переименованные и удалённые иконки.

Версии указаны на момент аудита; перед началом проверить актуальные через `bun outdated`.

## Вне области

- Рядовые обновления версий: они идут перед этапами, чей код задевают (решение mm-69).
- TipTap, Axios и Immutable: их удаляют, а не обновляют.

## Когда брать

Ничего не ждёт: можно брать в любой момент, когда это не мешает идущим этапам рефакторинга. Каждое обновление проверяется теми тестами, что уже есть в CI на тот момент.
