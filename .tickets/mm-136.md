# Обновить крупные версии инструментов: ESLint, Vite, TypeScript, Globals, Lucide

## Source

- [«Провести аудит зависимостей и конкурирующих библиотек»](https://github.com/dsc-sgu/mm-frontend/issues/71), дополнение «Ревизия доступных версий», cohort 9.
- [«Определить последовательность подготовки и выполнения рефакторинга»](https://github.com/dsc-sgu/mm-frontend/issues/69): крупные обновления инструментов вынесены из последовательности рефакторинга в backlog.

## Что сделать

Обновить крупные версии инструментов. Каждое обновление идёт своим PR со своими migration notes и проверкой `bun run lint`, `bun run build` и всех тестовых suites, которые к тому моменту есть в CI.

- [ ] ESLint 9 → 10 вместе с `@eslint/js` 9 → 10.
- [ ] Vite 7 → 8 вместе с `@vitejs/plugin-react` 5 → 6.
- [ ] TypeScript 5.9 → 7.
- [ ] Globals 16 → 17.
- [ ] Lucide 0.x → 1.x: проверить переименованные и удалённые иконки.

Версии указаны на момент аудита; перед началом проверить актуальные через `bun outdated`.

## Вне области

- Рядовые обновления версий: они идут перед slices, чей код задевают (решение #69).
- TipTap, Axios и Immutable: их удаляют, а не обновляют.

## Blocked by

- Ничего: можно брать в любой момент, когда это не мешает идущим slices рефакторинга. Каждое обновление проверяется теми тестами, что уже есть в CI на тот момент.
