# REV7.1: Брать и держать бронь проверки на время работы в редакторе проверки

Часть эпика mm-218. Перед началом прочитать [`docs/agents/remote-data.md`](https://github.com/dsc-sgu/mm-frontend/blob/main/docs/agents/remote-data.md) (обязательно по `AGENTS.md`).

Редактор проверки бронирует проверку при входе и держит бронь, пока преподаватель работает. Второй преподаватель видит, кто проверяет, и не перезаписывает чужую работу. Сам преподаватель может вернуть бронь из другой сессии.

### Делает

**Общий модуль `lease` уровня курса.** Серверный протокол брони (взятие, heartbeat, снятие, `423` с держателем) и адаптер проверки. Адаптер черновика курса добавит DRF4.

**Бронь проверки:**
- **Владелец.** Бронь покрывает проверку конкретной попытки, включая первую публикацию, и принадлежит сессии входа. Клиентского `leaseId` нет (ADR 0004).
- **Взятие** — автоматически при входе в редактор проверки. Страница попытки бронь никогда не берёт.
- **Запросы heartbeat** — примерно каждые 20 с, пока редактор проверки открыт, и сразу при возвращении на вкладку. Незаметно истёкшая своя бронь берётся снова. Если её уже взял другой преподаватель — `interrupted`.
- **Снятие** — при подтверждённом уходе из редактора проверки (точка из REV6.3) и при переключении попытки. Публикация бронь не снимает.

**Бронь занята при входе:**
- **Держатель — другой преподаватель.** Только чтение, «Проверяет X» и «Попробовать взять на проверку». Держатель обновляется при фокусе, автоматического захвата нет.
- **Держатель — сам пользователь из другой сессии.** «Открыт в другой сессии — на другом устройстве или в другом окне · Вернуть сюда» — перехват брони тем же пользователем.

**Публикация.**
- Условия публикации получают причину «бронь не моя».
- `lease-not-held` при публикации и потеря брони переводят редактор в `interrupted` с панелью «Неопубликованные изменения».

**Мок-бэкенд.**
- Бронь проверки по `AttemptId`: владелец — сессия, TTL 60 с, `423` с держателем, перехват тем же пользователем из другой сессии.
- Обобщение брони редактирования курса до брони по id ресурса, перехват и снятие при выходе из аккаунта — рабочие допущения mm-113, помеченные в обработчиках MSW.
- Канал только для тестов умеет сделать держателем брони другого преподавателя для REV-E4.

**До REV7.2** вкладки одного браузера делят бронь без координации и могут перезаписать правки друг друга. Риск такой же, как в текущем коде.

### Удаляет

- Имитацию событий брони проверки в RAM-моке списка попыток курса.

### Не входит

- Протокол вкладок — REV7.2 и REV7.3.
- Снятие брони при долгой неактивности — mm-135.
- Показ состояния брони в списке попыток курса из MSW — эпик «Список попыток курса».
- SSE — mm-98.

### Контракты

| id | Слой | Риск | Фикстуры | Контракт |
|---|---|---|---|---|
| REV-32 | Stateful | Целостность | `clock` | Бронь на поддельных часах: одна на браузер (сессию входа); heartbeat ~20 с и сразу при возврате на вкладку; незаметно истёкшая своя бронь берётся снова; взятая другим → `interrupted`. |
| REV-33 | Component | Целостность | `world:review` | Бронь занята при входе: только чтение, «Проверяет X», «Попробовать взять на проверку»; автоматического захвата нет; держатель обновляется при фокусе. |
| REV-34 | Boundary | Целостность | `world:review` | Страница попытки бронь не берёт; редактор проверки снимает бронь при уходе и при переключении попытки; публикация бронь не снимает. |
| REV-E4 | E2E | Целостность | `world:review` | Борис держит бронь проверки → Анна видит «Проверяет Борис», публикация недоступна. |
| TR-05 | Boundary | Корректность | `fail:http-500`, `fail:invalid` | Экземпляры шаблона для взятия, heartbeat и снятия брони. |

REV-32 в этом тикете проверяется для одной вкладки. REV-28 и REV-29 дополняются потерей брони и снятием после подтверждённого ухода.

Фикстуры описаны во вкладке «Fixtures» [матрицы](https://github.com/dsc-sgu/mm-frontend/blob/ddda126c5e73ec787362805c286ee081ee26244d/docs/prototypes/test-contract-matrix.html).

Связь с редактором страницы курса уточнена: адаптер общего протокола вкладок — mm-2ehnr-DRF5, который ждёт mm-232-REV7.3 и mm-c952d-DRF3. Старые пометки о брони курса/адаптере DRF4 заменены этой связью. DRF4 теперь означает конфликт блока; бронь сохраняется только у проверки. Обратную блокировку проверки редактором курса не вводить.
