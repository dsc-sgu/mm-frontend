# Запрототипировать предыдущий отзыв в повторном ревью

## Parent

#100

## What to build

Создать интерактивный throwaway-прототип повторного ревью, который сравнивает текущий переход к предыдущей попытке с компактным показом предыдущего общего отзыва рядом с новым diff. Прототип должен определить, сокращает ли такой контекст время проверки исправлений, не перегружая существующий экран.

## Acceptance criteria

- [ ] Представлен сценарий как минимум с двумя попытками, предыдущей оценкой, общим отзывом и новым diff.
- [ ] Можно сравнить существующее переключение попытки и компактный предыдущий отзыв в текущем ревью.
- [ ] Полная предыдущая попытка остаётся доступной в обоих вариантах.
- [ ] Прототип не переносит и не переякоривает исторические построчные комментарии.
- [ ] Проверены развёрнутое и компактное состояния на типичном desktop-экране.
- [ ] Результат фиксирует, стоит ли реализовывать представление, какую информацию показывать и где проходит граница с полной историей.
- [ ] Прототип сохранён как первичный источник по правилам `/prototype`; production-код не изменён.

## Blocked by

- None (can start immediately).
