# Переименовать frontend identity попытки в attemptNumber

## Parent

mm-63 «Согласовать карту реализованной frontend-системы»

## What to build

Сделать пользовательскую identity попытки точной: URL и frontend vocabulary должны использовать порядковый `attemptNumber` в контексте курса, задания и студента, а не создавать ложное впечатление глобального attempt ID.

## Acceptance criteria

- [ ] Route parameter и все frontend consumers называют значение `attemptNumber`.
- [ ] Номер остаётся числом, scoped к course + task + student.
- [ ] Breadcrumbs, navigation, query identity и mock data используют одну терминологию.
- [ ] Переход между попытками и прямое открытие существующих URLs сохраняют корректное поведение.
- [ ] В frontend-коде не остаётся `attemptId`, обозначающего порядковый номер.
- [ ] Lint и build проходят.
