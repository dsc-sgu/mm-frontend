# Применять панель Task по Ctrl/Cmd+Enter

## Source

- Страница AnyType «Ругаюсь на Moodle», «Как это можно улучшить» (создание заданий): «Добавить горячую клавишу подтверждения формы, например `Ctrl+Enter` / `Cmd+Enter`».

## Проблема

Панель Task проектируется в [#180](https://github.com/dsc-sgu/mm-frontend/issues/180) и прототипе [#181](https://github.com/dsc-sgu/mm-frontend/issues/181). Её спецификация заменит [#41](https://github.com/dsc-sgu/mm-frontend/issues/41) и [#106](https://github.com/dsc-sgu/mm-frontend/issues/106). Горячая клавиша подтверждения нигде из них не упомянута. Teacher, который создаёт подряд десяток Task через «Создать ещё», каждый раз тянется к мыши.

## Что делает

- Ctrl+Enter (Cmd+Enter на macOS) выполняет основное действие панели:
  - для новой Task — «Создать»;
  - если включено «Создать ещё» — создать и открыть следующую;
  - для существующей Task — применить правки.

  Что значит «применить» в моделях A и D из #180, решится после #181.
- Клавиша работает из любого поля панели, включая редактор условия.
- Рядом с кнопкой показана подпись клавиши, как у других подписанных shortcuts (`src/features/keyboard/shortcut.ts`).

## Что решить

Конфликт клавиш. В редакторе Course Page Mod+Enter уже выводит курсор из блока кода или цитаты (`exitShortcut` в `src/features/course/features/page-edit/model/block-exit.ts`). Если условие Task редактируется тем же профилем Plate, одна из двух команд должна уступить.

## Связи

Пункт для спецификации «Настройка Task и Task Groups», которую пишут после прототипов #181, [#190](https://github.com/dsc-sgu/mm-frontend/issues/190) и [#191](https://github.com/dsc-sgu/mm-frontend/issues/191).
