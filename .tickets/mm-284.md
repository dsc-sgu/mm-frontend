# Показывать понятную страницу «Не найдено» для неизвестного адреса

## Проблема

В `src/main.tsx` и `src/routes/__root.tsx` не задан `notFoundComponent`. На неизвестный адрес TanStack Router показывает своё английское «Not Found» без шапки и без пути назад. Для курса это уже решено (ACC1.2: явный 404 курса), а для адреса вне курса — нет.

## Что делает

- `defaultNotFoundComponent` у роутера: русский текст «Страница не найдена», шапка приложения, кнопка «На главную».
- Невошедший пользователь на неизвестном адресе видит ту же страницу без пунктов меню пользователя.
- Компонентный тест на маршрутном дереве приложения: неизвестный адрес показывает страницу «не найдено».
