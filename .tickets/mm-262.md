# Запретить if без фигурных скобок: включить curly и переписать существующие

### Делает

Включает правило `curly: ['error', 'all']` в `eslint.config.js` для всего `src/` и `playwright/` и переписывает все места, которые оно находит.

Сейчас тело `if`, `else`, `for` и `while` можно писать без фигурных скобок, и в коде смешаны оба стиля:

```ts
if (result.status !== 'published') throw new Error('Expected a Review');
```

Нужно писать так:

```ts
if (result.status !== 'published') {
  throw new Error('Expected a Review');
}
```

### Как включать

- Правило ставится **после** `prettierRecommended` в `eslint.config.js`. Иначе `eslint-config-prettier` его выключит: он отключает `curly` как правило, конфликтующее с форматированием. С вариантом `'all'` конфликта с Prettier нет.
- `curly` чинится автоматически: `bunx eslint --fix src playwright`, затем `bun run format`. Ручная переписка не нужна. После автофикса стоит просмотреть дифф на случай длинных однострочных `if … else …`.

Поведение не меняется. Это чистый refactor.

### Не входит

- Тернарники и `&&` в JSX: их правило не касается.
- Другие правила стиля условий, например `no-negated-condition`.

### Контракты

Контрактов в матрице нет. Проверяет правило ESLint.
